## 偏差

1. **现象**：票面验收 3 说 C-正6 题干「question 字段取自 `eval/results/frames/C-C-正6.json`」，该帧文件无 question 字段（仅 frames/parsed 两键）。**原因**：C 组帧采集脚本未落 question。**处置**：题干取自 `eval/answers/C-题目与答案.md` C-正6 行「累积亏空当前多少？与二季度比变化如何？说明什么？」（与帧内 match 帧「命中『累积亏空』」证据自洽），测试文件内已注释声明出处。
2. **现象**：覆写时序＝票面指定位置（N5b 段，verdict 帧发射之后、`_run_chain` 之前）。**后果（设计使然，供中途审查拍核对）**：流内 verdict 帧展示 LLM 原裁决链（透明留痕），N5b note 记回退，N6 note 与 `chat_run.verdict` 终态（`_finish_run` 用同一被覆写 dict 落库）＝实派「检索问答链」——终态持久值与实派一致。**处置**：按票面「N5 裁决后、_run_chain 分派前」执行，无改。
3. **现象**：已注册三链的 N5b note 文案由「在 17 链清单内——核验通过（闭世界枚举）」改为「在 17 链清单内且已接线——核验通过（闭世界枚举＋注册面）」。**原因**：核验语义升级后旧文案只叙事闭世界，构成两套叙事。**处置**：随票更新；无测试钉住旧文案，评测帧为历史数据不受影响。
4. **现象**：TDD 红绿时序未分步留证（实现与测试同拍落地、单一 commit）。**原因**：执行为单次作业。**处置**：测试与实现均在 commit 8a50d78 内，全绿可复核。
