## token 成本影响量化说明（估算）

- 变化本体：读面 `IndexHit.text` 由 `min(hit_text, 500)` 变 `min(hit_text, 1024)`；smart 片段带 256~1024 字（合同常量 SMART_MIN/MAX_CHARS），故新窗即全文不截。
- 单 hit 均长估算（片段长按带内均匀近似）：旧 E[min(X,500)] ≈ **461 字**，新 E[X] = 640 字，**约 1.39x（+179 字/hit）**。真实切段按语义边界非均匀，量级估算成立；混合/fixed 档子块 ≤512 字者 text 不变（旧窗已覆盖）。
- 每题影响：text 只进检索链生成材料 prompt（S4 命中携出），典型 4~8 支命中（B-反1 实引 4 条）→ 每题生成 prompt 约 **+0.7~1.4 千字 ≈ +500~1000 token**（按中文 1 字≈0.7~1 token 粗算），相对「系统提示＋全部装配材料」的典型生成 prompt 约两成上下增量；答案侧 token 零变化。
- 零变化面：检索打分恒用 `hit_text` 全量（切片不参与打分）、embedding/入库管线、chunk 逻辑均未触及——新增成本只在生成材料携出一段。
