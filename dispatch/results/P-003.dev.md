## 疑点（待 L0 裁决，不动手）

1. **V1 A9 置信度配额未随移植**：V1 llm 档用文档置信度**分配窗口席位**（DOC_CONF_FLOOR/MAX_SEATS 轮转发放）；V2 按票面「同窗规则在供给层硬编码——不依赖 LLM 自觉」将窗口构成完全收进 supply_window 硬规则，LLM 置信度只**重排来源块序**（供给硬规则在其下游仍生效，配额/同窗/保底席不可被 LLM 破坏）。A9 席位配额算法本票未移植——是否挂账（归属：V2-05 tools 层或后续精排调优票），请裁决。
2. **supply_window 配额常数未经拍板**：hints 命中族共享 3/4 预算（每族 ≥1）、其余族每族保底 1 席、族内同报告至多半额（cap//2，V1 G-06 同式）——常数集中在 `domain.supply_window`（Owner 可调），数值为本票实施值非合同值。
3. **真网关冒烟门控**：`RETRIEVAL_SMOKE=1` 每轮真实调用 MiniMax 两次（量级约 1k token 进＋短出，与 V1 FAQ_SMOKE 同档）；不进门禁。是否纳入某验收批例行跑一次，请裁决。
4. **anchors 语义落法**：`RetrievalNeed.anchors`（@ 锚定资产名）本票落法＝并入关键词腿检索单元＋编号保送通道（docstring 注记为 V1 S1 锚定材料语义的检索侧投影）；无独立锚定证据路（V1 装配层六路属 runtime/tools 层，非本票边界）。若 tools 层（V2-05）对 anchors 另有合同语义，随其票对齐。
