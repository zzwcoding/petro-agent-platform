## LLM 调用成本（每篇一次结构提取的量级）

- **触发面＝入库 chunk 步独占**（smart/mixed）：每篇文档**每版本恰一次**调用（caller=`kb.ingest.structure`，gateway 记账归因）；fixed 模式零调用；同版本重入（重跑/重试）**零调用**（版本缓存命中）。不在检索热路径（票册拍板基线 3「入库结构图＝离线批量」兑现）。
- **量级估算**（评测报告同规模 4.5–6k 字文档）：prompt＝逐行编号文本（约 6k 字＋每行 5 字符行号开销 ≈ 7k 字符，CJK ≈ 每 token 1–1.5 字，约 5–7k token）＋提示词骨架约 250 字；completion＝标题行 JSON 数组（30 行标题量级 ≈ 0.5–1k token）。单篇单次合计 ≈ 6–8k token，与一次 `kb.ingest.summary`（截 6000 字）同量级。
- **硬上限**：单次入库结构提取 ≤1 次调用（提取成功即缓存；任何失败路径立即落规则图，不重试不二次调用）；30s 有界超时；超 20000 字符逐行文本直接走规则图（零调用）。
- 测试侧全程桩 LLM 永不触网（B6 红线）；本票开发期未发生真实模型调用。
