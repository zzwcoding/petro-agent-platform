   取 resolve_actor 上游解析的 `Actor.who`（ask 命令自带；resume 段回读 run 簿记行 actor

   无法精确入账——审批决定行/恢复段终态行 who 落 run 创建者。处置：如实登记挂账，
   **归属：待 L0 裁决**（若裁决精确归属，需 AgentRuntime.resume 增 actor 槽＋api 透传，
   建议立小票）。

   落为四事件类（终态一类两值、审批决定一类两值）；拒答收口与 run_completed 互斥
