# ADR-0005 · 子任务图＋前置条件机（Owner 设计拍板 2026-10-09）

- 日期：2026-10-09
- 背景：ReAct 骨架真网关实证暴露"数据路径退化"——模型把 3 轮额度全花在 discover
  （犹豫空转），永不发射执行。根因三层：指南无发射判据／无语义工具边界／缺业务红线
  （单井不支持→全井发射）。Owner 提出子任务图设计，L0 精确化。
- 决策：**一轮＝四相位**——①业务澄清（LLM＋discover，产出带台账注释的问题组，子问题
  ≤4）→ ②工具匹配（LLM 提议子问题→工具/链，schema 收口）→ ③**前置条件机（纯固定
  代码，LLM 无权判定）**：逐子问题过闸（禁用词/新鲜度窗/在册绑定态/外表越集/单井支持性）
  判四态（pass｜blocked_ask→ASK 挂起｜blocked_refuse→子问题如实拒答｜note 注记）→
  ④批量执行＋LLM 汇总（verify 核验收口）。
- 铁律：**LLM 出语义（澄清/分解/提议），代码出判定（前置条件机零 LLM）**——V1 十七站
  瀑布教训的落点。
- 轮语义（Owner 拍板）：整循环 3 轮——轮 1 得部分答案，轮 2/3 只带失败/缺失子问题＋拒因
  回炉业务澄清；成功子问题结果保留不重跑；ASK 挂起不占轮。
- 澄清相位预算（Owner 拍板放宽）：发现调用 ≤10，每次 discover 计数埋点留档做分析。
- 后果：**V2-28 五站能力迁移由此收编**（禁用词/术语卡/FAQ/新鲜度/越集审批＝前置条件机
  检查项），V2-28 票随实施票关闭；V2-34 为实施票。
