APIN薄端点：鉴权、参数校验、事件桥接端点薄层，编排语义全在运行时编排与执行
OR编排与执行：图装配、命令受理顺序由它定，业务相位不许互相调用全部业务相位
BK公共簿记：全节点共享的写入面步记录/序号/触界收敛集中一处，禁各节点自行直写状态与限额（落库）
UD读题：装配任务书 → 模型读 → 定路由语义判断交模型；程序只按结论分派澄清 或 直接作答
GT安全阀：词面闸，命中即不放行不是防线，只作明显情况的早退；真正保证在执行层编排与执行（拒答收口）
BG废弃词闸：判据交模型，程序只按结论分派提及旧名可放行，但不许按旧口径出数工具匹配（出数只认现行口径）
CL澄清：反问挂起、分解问题问题或口径有歧义时停下来问清工具匹配
TM工具匹配：子问题 → 工具，闭世界对账语义类判断（提旧名 vs 要旧口径）在此收口前置检查
PC前置检查：逐子问题过闸纯程序零模型，语义判断已上移到工具匹配批量执行
EX批量执行：发现、执行、观察回流只读子问题并行；失败子集带拒因回炉作答
AN作答：材料渲染、逐句带出处、真流式推出每句话都要能指回材料核验
VF核验：逐句核对有没有材料撑着零模型的机器底线，防编造作答收口
ST状态与限额：运行状态、四道限额状态形状是全体共用地基，限额集中一处声明全部相位
PR指令与提示词：任务书、各轮合同文本只出文本不做判断；文本变与格式变是两件事读题／澄清／作答
PS解析与发射：模型输出解析、格式校验模型输出是外部输入，要按契约解析读题／澄清／工具匹配
CX上下文：材料段、过程档案、台账注入模型每轮看到的材料经确定性编译作答
TR2事件通路：九类事件、断线续推事件名是闭世界；断线要能接上接口层
PE存储归档：运行记录、黑匣子、审计只追加不改；审计唯一写口基础设施层
GW网关桥：模型调用唯一出口模型出口单点，记账与限流才有唯一字段语义基础设施层
TLR工具注册表：五个只读工具agent 与世界的唯一接触面引擎层
PCM前置条件机：纯固定代码过闸零模型；闸件本体在工具层，运行时只消费回到前置检查相位
