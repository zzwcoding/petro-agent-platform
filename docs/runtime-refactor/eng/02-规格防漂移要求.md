## 一、结论摘要

规格要能防漂移、防降级，光靠「七节模板写全」不够——**现行模板里真正有机器消费面的只有三节（触及的模块／验收测试／边界规则），而防漂移最吃劲的三节（不做什么／行为约定／依赖与风险）全是散文，没有任何闸或人审工序把它们变成「验收对象」**；同时**本仓自称「六道闸全绿」里，spec gate（`tools/check_specs.py`）根本没有接进 CI，也没有看守测试，票 shape/close 两闸同样只在手工派发时跑**——这正是 sdd-flow 核心原则 7「文档里写着却没有闸的禁令等于不存在」在本仓的自证。因此「不漂移」要补的是：每条硬要求都写明**对应闸或对应测试标识**，数字/枚举/口径只许引单点真源不复述；「不降级」要补的是：框架承诺逐条落成 import 闸条目、任何截断/缺失必须带机读信号 + 测试断言、降级必须走 ADR 且规格里预先声明合法降级路径。本次共 **L0 四条**（spec gate 未接线／三节无消费面／框架承诺无挂钩／覆盖率闸不覆盖 appv2）。

## 四、「不漂移」补充要求（第 3 问）

面向「接口先行／测试锁行为／边界即闸门」三原则，规格必须补：

1. **接口定义：精确到可写接口测试**。字段名逐字、类型、必填/可选、**枚举闭世界（列出全部合法值 + 越界行为）**、错误情形（错误码/异常类型）。真源仍是模块卡，但卡里同一处也必须精确；spec 引卡不复述。锚点依据：`module-spec-format.md:26-27`；失败先例 `R-DP.md:114`。
2. **行为约定：「可判真伪的陈述句」判据要写成硬要求**——判据 = **这句话能不能直接写成一个 `assert`**（给定输入 → 可观察输出/报错/发出的机构信号）。反例：出现「尽量／合理／必要时／视情况」即不合格。锚点：`module-spec-format.md:30,156`（写作纪律「不写无法判断的话」）。
3. **数字/上限/口径只许引真源、禁内联复述**：本工程所有数值（轮数/发现/澄清/子问题上限）已裁决收成一处（`walk/裁决表.md:83` §06-A；`walk/17-全树收官总览.md:27`），规格里出现数字必须写「真源：<文件#节>」，**禁止写裸字面值**——这一条直接治 S3 的 C-01..C-11。
4. **横切事实单点化**：事件类数、模块名、端点清单这类被多份规格引用的事实，只在一处定义、其余引用（治 `agent-loop.md:47` vs `modules.md:484` 的 8/9 矛盾）。
5. **不变量与状态机引用而不复述**：`INV-x` / `a→b` 只引 ID，原文只在 `CONTEXT.md` 语义核心（`module-spec-format.md:134`）。
6. **「不做什么」必须带替代落点锚点**：每条排除写「不做 X → 由 <模块/端点> 承担 → 锚点 file:节」，否则排除项可能在实现期变成静默缺失。
7. **验收测试补「保留集/边界集」两栏**：「应当改变的样本 + 不应受影响的样本」成对，只测前者会把过拟合当进步。锚点：`research/最佳实践-工程组织.md:100`（主题④-9）。
8. **规格里每条硬要求附「挂钩」**：写明对应的闸名或测试标识或「人审（原因）」（见第六节）。

**特别回答：规格里的「不做什么」和「框架红线」能不能机检？**

- **「框架红线」能机检（较强）**：「不许用 A 替代框架 X」→ import-linter forbidden contract（`appv2 禁引 X` 或 `只许 X 在 <块>`），依赖出现即「真引入」的弱判据成立；「真的调用 X」纯静态判不了（import 不用也过闸）→ 必须**补一条行为测试**或 AST 调用点扫描。锚点：`tools/importlinter_v2.toml`（R5b、B6 契约）；AST 双证先例 `specs/agent-loop.md:137`。
- **「不做什么」现状接不上（弱）**：像「不保留旧两行式契约」「不做澄清/不查数」这类范围排除**无语义之外的机械判据，无法机检**。能做的是**降维**：凡是「不做」可以翻译成 (a) import 方向禁令 → 转边界闸；(b) 端点/路由禁令 → 扩覆盖率闸闭世界；(c) 「不许出现 X 符号/模块」→ 自写 grep/AST 断言测试。剩下纯范围排除 → **只能进票面 + 人审**，并说明「为什么接不上」（无形状/存在性/退出码判据，不符合 ticket-gates.md:80 的落闸三条件）。
- **「不许静默降级」可机检（部分）**：机读信号字段存在性 → 写一条 pytest 断言；挂账短语 → 扩债务标记闸扫描面到 `appv2`。锚点：`arch/P7a:98`（红线原文）。
