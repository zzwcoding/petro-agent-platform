## 一、这块是干嘛的

每次叫模型干活，除了指令，还得给它**材料**：查到的数据片段、台账名录、这台机器这一趟已经做过什么。**上下文块就是负责准备这些材料的那一块**。它管五件事：

1. **材料段渲染**——把观察到的材料排好序、编好号（`[n]` 引标，「第 n 份材料」的意思），渲染成给模型看的那一段文本；
2. **过程档案段渲染**——把这趟运行已经做过什么，压成一段**有界**（有长度上限）的摘要，防止模型重复劳动；
3. **台账与名录投影的取得**——从工具那边取一次台账全量数据放进状态（只取一次，后面各轮复用）；
4. **对话链追加面**——超窗时把老对话压成摘要（compaction），只改「给模型看的视图」，不改原文；
5. **材料面 Manifest 编译**——每次调用都留一份「这次给模型看了什么」的材料账，说清来源、数量、有没有截断。

它的定位是**确定性渲染与装载**：全部动作都是闭世界查表、排序、计数、截断、字符串处理——**零语义判断**（不判「哪支材料有用」「答没答上」）。

一句话记住它：**管材料与对话窗口：渲染确定、有界必披露、装载只取一次。**

## 二、它和邻居怎么打交道

一句话：它**只依赖两块**（状态块的字段形状、工具块的公开取数面），**向三个消费方交出材料段与材料账**。

- **谁给它料**：状态块（字段形状、材料清单的十个字段、常量；本块对它**只有一个写入点**——台账投影取一次装进状态）；工具块（台账／名录投影的**唯一世界接触面**，只经公开面，不直引检索引擎、不直连数据库）。
- **它给谁用**：
  - **作答块**：用材料段与材料账。
  - **决策轮装配**：用过程档案段文本（只读渲染产物）。
  - **编排面**：掌握装载时点、追加编排、压缩的唯一调用点。
- **它不碰谁**：常驻块的包裹文本与逐字转抄渲染、任务书／各轮指令装配（归提示词块）；链上消息的物理追加与追加时点、相位包一次性重发判定（归簿记块＋编排）；材料截断的通知帧发射与披露文本（归作答块＋事件通路块）；材料清单的用量与归因记账（归簿记块的调模型单点）；过程档案的写入点截断（归簿记块）；黑匣子回放、旧检查点字段读入（归存储归档块／状态块）；材料挑选、工具结果归一、大结果落引用（归执行块）；模型调用（归网关桥，本块连那个出口都不引用）。
- **它在图里的位置**：

```
state（字段形状 + Manifest 十字段 + 常量）      tools（台账/名录投影唯一公开取数面）
        │ 唯一写入点＝ ledger_dump 取一次装载
   context（本文这块：材料段 / 过程档案段 / 装载 / compaction / 材料账）
        │
        ├─→ answering（材料段 + Manifest）
        ├─→ 决策轮装配（过程档案段文本）
        └─→ orchestration（装载时点、追加编排、压缩唯一调用点）
```

## 三、关键行为逐个讲

规格的「行为约定」共 14 条。逐条翻译。

**行为 1｜材料段渲染形逐字迁移**（承载位换、文本不变）。规格：文本以段头起——逐字「\n观察材料：\n」；块形＝`[{index}]（{label}）{content}`；`index`＝观察自带的全局序号（**不是渲染位次**）；`label`＝非空段以全角「｜」连接、**段序为 信任级｜来源｜井**（空段跳过；来源与井两段经去空白归一后判空，空白串算空段跳过）；三段全空＝空括号 `（）`（这是现状固有的，迁移不修）；`content` 缺失＝空串；空材料集正文＝逐字「（无）」。人话：材料段的排版一模一样地照旧搬过来：段头一行、每条材料一行「[几]（标签）内容」，标签按「信任级｜来源｜井」的顺序拼、空的跳过，什么标签都没有就留一对空括号，一份材料都没有就写「（无）」。术语：**信任级**＝这份材料有多可信（权威台账／台账／检索报告三档）。

**行为 2｜信任级映射闭世界＋notice 排除。** 规格：判定路径唯一（只读 `locator.kind`，字符串归一后查表；缺 `locator`／缺 `kind`／未知 kind 统一落 `report`——**不抛错**）；映射闭世界＝**十 kind 三族**（权威：`agg_row`／`lineage`；台账：`metric`／`term`／`object`／`relation`／`family_annotation`；检索：`fragment`／`graph`；`notice` 名义入表但**材料段整体排除**——不进模型面、不计任何计数）。人话：材料来自哪儿决定它算哪档信任级，一共十种来源分三档；事件通知类的那一种只在表里占位、永远不进材料段、也不计数。术语：**闭世界**＝合法取值只有清单上这些，清单外一律算错。

**行为 3｜排序＝信任级稳定序。** 规格：权威＜台账＜检索（rank 0／1／2，同 rank 保持入栈序、稳定排序）；两跑逐字相等（确定性不抖动）。人话：越可信越靠前，同档的保持原来顺序。

**行为 4｜分承载体预算（分形帽）。** 规格：权威／台账族（信任级非检索）**恒全量渲染、不设条数帽**（引擎侧已封顶，装配不重复封顶）；检索族超帽才截断（**帽只作用检索族**）；帽值经注入参数传入，**数值单点在常量里**（具体值不落本规格）。另有一处分工说明：单个大结果「落引用」归执行块（不归本块）；**本块的检索族条数帽是 token 安全面，与「渲染帽裁剪」不是一回事**。人话：权威和台账那两档**一条都不许裁**，只有检索片段这一档在太多时才按上限裁——这是为了不让给模型的材料爆掉。

**行为 5｜截断必披露（模型面披露行逐字）。** 规格：检索族截断时材料段尾接披露行，逐字为「（材料披露：检索片段共 {检索支数} 支，本轮渲染前 {实渲支数} 支——未渲染片段不在本轮视野，不得对其断言；权威行集与台账卡已全量渲染。）」；未截断样本**零披露行**（零残留）。人话：裁了就一定要明说「一共多少支、只给了几支、没给的不许编」，没裁就一个字都不许多写。

**行为 6｜材料账的三个机检字段与选材理由。** 规格：`material_truncated` ⇔ 检索族截断（未截断恒 False）；`material_rendered`＝权威／台账族支数＋实渲检索支数；`material_total`＝排除 notice 后的材料总数；**零材料步＝(0, 0, False)**；`selected_reason` 按逐字形拼装——带材料两形：「步骤 {step}：信任级降序稳定排序；权威 {A} 支全量；」＋ 截断形「检索片段帽 {帽} 支截断（{M}/{R}）」或未截断形「检索片段 {R} 支全量」＋「（合计入选 {K}/{总}）」；**零材料步形**＝「步骤 {step}：理解步零材料渲染」（迁移照抄）。槽位含义逐字：{A}＝权威／台账支数、{R}＝检索支数、{M}＝实渲检索支数（＝min(检索支数, 帽)）、{帽}、{K}＝合计数、{总}＝材料总数。人话：每次调用都留一张材料账，写明「一共几支、真给了几支、有没有裁」；还有一句人话理由，格式和字样都定死了。

**行为 7｜每次模型调用都有材料账且材料标来源。** 规格：材料账由本块编译、随步落地（缺位＝判失败）；`source_type`／`source_id`／`version`／`trust_level` 四个列表**逐条对应同一来源序列（等长）**——来源序列＝**本次实投材料逐支（实渲支）**＋**当轮投入常驻块时**其三块来源行（决策／澄清／工具匹配三类首入**恰 3 行**、作答轮**零常驻行**；通知不计）；三元组映射的唯一落点是常量 `RESIDENT_SOURCE_ROWS`（`ledger_dump`→`ledger_full_dump`／`alias_dump`→`ledger_aliases`／`schema_card`→`schema_cards`）；`transform` 取形状缺省。人话：四列来源信息必须一样长、一一对上；常驻投入的三块台账在自己的首入轮各占一行，作答轮没有；空串也如实写（图谱没有锚边的情况就是空的），**不许假装有值**。术语：**常驻块**＝每轮都随指令给模型的台账／名录那几块固定内容。

**行为 8｜过程档案摘要段有界（逐字迁移）。** 规格：零档案＝零段（返回空串，调用方跳过，首轮零噪声）；头注逐字「【本 run 已做（过程档案摘要——防重参考，不是作答材料）】」；条目行形 `- [{phase}] {title}｜{digest}`（相位缺失＝`?`、标题／摘要缺失＝空串——现状缺省回落，迁移照抄）；预算含头注起算、逐条累加、超即止（预算值＝注入参数，**数值单点在常量里**）；超预算追加披露行（条数前后账）——逐字「-（过程档案摘要有界截断——已渲染 {n}/{N} 条）」——并停止（披露行免预算复检，这是现状固有的，来源疑点如实登记）；**这一段永远不作对话轮**（只作当前指令的材料片段，由调用方拼接）。人话：过程档案永远是一段有长度上限的摘要，超了就在末尾明说「已渲染 n／N 条」；它只是一段材料，不是聊天记录。

**行为 9｜超窗压缩＝模型视图压缩（钉的半面；依票面重落——无现状载体）。** 规格：对话消息总量超视窗（触发参数注入制、无裸值；**数值已裁 8k 档**，承载位已定为状态里一个独立字段）→ 自尾向前保留近期轮（**保留窗保证三语**：保留窗自尾向前累积、**至少 1 轮——最新轮恒在场，哪怕单轮超预算**；**单轮独占预算（巨轮）＝原样放行零压缩**）；最旧的「对话轮对」（用户＋助手）摘要化（**摘要＝系统消息、置于角色红线系统消息之后、近期轮之前**）；**合同与相位包永不摘除**（识别面是**结构化**的——标记随消息条目字段携带，**键名已定＝`origin`**，或由调用方以链位贡献表随调用传入；本块不采内容子串识别）；**压缩的唯一调用点＝调用方（编排面）**；摘要形逐字：摘要头「（前情摘要——旧轮原文已压缩，完整原史在会话档案可查）」＋「问：{问句原文截 120}」「答：{答首行截 120}」行（**截数 120**）；**只作用于模型视图——`state.messages` 零覆盖**（只压不删、原史全量在检查点可查）；**压缩触发是「前缀延伸／缓存命中」的显式例外**（触发即断缓存，留痕前缀断言按此豁免）；披露账目（轮数前后账＋原史可查注记）**追加在选材理由之后（分隔「；」）**，由调用方在合成最终材料账时执行（本块只返回账目串）。预算内**原样返回、披露为空**（零漂移）。人话：对话太长时，把最老的几轮压成一段「前情摘要」放进给模型看的视图里——**原文一个字都不删**（原文在存档里随时可查），最新一轮无论如何都在，合同与相位包永远不摘；压缩只在「给模型看的那一份」上做，而且压缩是谁触发的、就由谁写进账目。

**行为 10｜台账投影取得：经工具公开面、取一次。** 规格：取得路径唯一（经工具块公开面只读；不得直引引擎、不得直连数据库）；「取一次」＝状态里的台账投影**不是空就用原来那份**（**含空投影＝「已取到的空态」、不再取**；只有还没取过才去取；快照随检查点走、后继轮复用）；空 → 取得并写回状态（**本块唯一状态写入面**）；返回的是**副本**（改返回值不改状态）；消费面只读状态投影渲染。人话：台账全量数据**一辈子只取一次**，取到了（哪怕是空的）就一直复用；别人拿到的永远是复印件，改不动原件。

**行为 11｜取得失败＝run 终局失败（fail-fast）。** 规格：台账／名录投影取得失败（**「失败」判据面＝工具面返回失败态 ∪ 调用异常捕获面**，判据就此定死）→ **run 直接终局失败＋用户面输出稳定错误提示**（失败即收场，**不带缺台账的投影续跑**；三态收口归编排面）；**材料账的过程注记留痕义务保留**（失败事实记进过程档案——机读披露，不静默吞失败）；用户面走事件通路块既有的失败腿（`run_failed` 通知＋正常 `done`；`error` 帧只用于流级〔帧通路自身异常〕）；本块**零编造**（不冒充已取得；**合法空投影与失败不同路**——工具成功返回空≠失败）。人话：台账取不到就直接认输、给用户一句稳定的错误提示，绝不「在缺数据的情况下硬答」；但要区分清楚——**「取到空」不是失败，「取不到」才是**。术语：**fail-fast**＝发现拿不到关键材料就立刻收场、不硬撑。为什么：规格写明这是 Owner 翻案——原裁决是「如实空投影不炸链」，被否决，理由是辅助材料失败还硬撑会产出缺材料的低质答案，宁可诚实报错。术语：**fail-closed / 不静默**是全仓的总红线。

**行为 12｜渲染器族纯函数确定性＋IO 面单点。** 规格：五个渲染／判定函数同入参两跑逐字相等（或深比较相等）、**调用前后入参深比较相等**（零写入）；零 IO、零模型调用、零时钟读取、零随机、零事件发射；**唯一 IO 面＝台账装载的那一次工具调用**。

**行为 13｜程序不判语义。** 规格：本块全部判定＝闭世界查表／排序／计数／截断／字符串归一／字符截取——零词表零正则语义判定；豁免面＝形态处理（集合成员判定、字符串归一、字符截取）。

**行为 14｜本块零合同零指令。** 规格：不定义、不复制合同常量文本与指令骨架（材料段／过程段是唯一文本产物面）；相位包组成与重发判定均不落本块。

## 四、施工时要注意的坑

- **合法降级路径＝无**：台账取得失败＝fail-fast 终局失败（不是降级）；其余**无降级**——材料渲染不删段、不改写、不缩措辞、不冒充。
- **截断／压缩必披露（机读信号三面分工）**：(a) **模型面**——材料披露行、压缩摘要头逐字在场；(b) **机读字段**——材料总数／已渲数／截断标记＋选材理由的帽账＋压缩披露账目＋台账装载失败留痕；(c) **用户与审计面**的截断通知＝**发射方义务**，**本块零帧、不冒充覆盖**。
- **本块零静默省略**：不输出省略号形占位；一切有界处理（帽／预算／视窗）都必须用披露行或披露账目明说。
- **红线原文（逐字）**：「红线——不许静默：任何相位仍发生截断，模型面必须随材料段带明示「（材料仅渲染 N/M 支）」，收口注记面同步披露（对齐 V2-53「注入不进交付面」诚实纪律）」——规格注明其中「（材料仅渲染 N/M 支）」只是**示意形**，操作形以行为 5 的锁定稿为准。
- **只经工具公开面接触世界**：禁直引检索引擎、禁直连数据库；**不引旧码**（「迁移照抄」是把旧码字面搬进新块、不是引用旧模块）。
- **依赖白名单＝状态块＋工具块**：禁引其余运行期块；**零模型调用**（连网关桥都不引用）。这两面都**没有专属机器闸**（规格明确「诚实声明」），靠静态断言＋人审。
- **写入面单点**：全块唯一状态写入＝台账投影的取一次装载；其它共享写面（消息链／步记录／通知／过程档案／对话层／路由意图）**零写**（写口归簿记块）。这一面也无专属闸，靠 AST 扫描＋人审。
- **禁手写替代（渲染单点）**：材料段渲染／过程档案渲染／信任映射／帽常量／三来源行映射在运行期面内各恰一处定义，禁相位块另存副本（旧码病灶：渲染函数与消费点分居两个文件）。
- **已知未定／登记项（照实说：还没定）**：
