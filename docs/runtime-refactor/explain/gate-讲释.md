> 规格改，本文即废；本文与规格冲突，以规格为准。
> 日期：2026-10-16。写给人看——没跟过工程的人也能读懂；给机检看的断言一条都不在这里。

## 一、这块是干嘛的

用户的问题是入口的第一道关。**安全阀块负责把入口问句里「明显中招／越界」的三类情形挑出来**，命中就不放行、用固定话术拒答收口。三类是（**三族闭世界**）：

- **注入**（`injection`）——试图让系统忘掉自己的规矩，比如「忽略之前……」「ignore previous」这类要求；
- **外发**（`outbound`）——要求把数据发到平台外面去，比如「发到邮箱」；
- **写意图**（`write`）——要求改动生产参数，比如「把配产改成多少」「删除台账」。

它做事的方式是：**零模型、零执行的一次词面早退**。「**早退**」＝命中就直接收口、不进后面的流水线。

有一句定位必须讲清楚，否则会把它想得过重：**本块是辅助快路径，不是防线**。它命中就早退的好处是「省一次模型调用 ＋ 给用户一句友好的固定话术」；但**「只读」这条红线的硬保证在执行层**（系统根本没有写／外发的工具、连接是只读的＝结构保证）。**本块漏判了，由执行层兜**。

它用的是**词面**手段（固定词表子串／共现），这是**结构早退、不是判据**：它**不做任何语义判断**——不做豁免判定、不猜用户意图、不判「提及 vs 执行」。废弃词闸（判断旧口径是「被提到」还是「真要执行」）**已经整体移出本块**（判断归工具匹配块的模型产出、分派归前置检查块判定序第 1 位）。

一句话记住它：**三族词表快路径早退：命中就给固定话术，漏了由执行层兜。**

## 二、它和邻居怎么打交道

一句话：它**只吃一段纯文本**（入口问句），**只吐两态之一**，别的一概不沾。

- **谁给它料**：调用方传入的入口问句文本——**纯文本进出，本块零状态字段读**；它依赖的唯一资料就是**模块内自带的闭世界词表常量**（不读台账／名录／文件——**命中路径零 I/O**）。测试夹具是一份固定词表 fixture（只用于测命中面）。术语：「**fixture**」＝测试用的固定样例数据。
- **它给谁用**：**入口消费方（理解相位）**——由它执行早退位次与收口落账；**编排面**——收口时点与链同步。
- **它怎么交付**（信号形状由本块锁定，**发射与落账是消费方的义务**）：
  - notice 恰三键 `{type, gates, content}`——`type="refused"`、`gates=[]`、`content=Refusal.content`；
  - 步记录：`decision` 类，标题＝三形逐字（见下），载荷＝`{"phase": "understand", "gate": <分型>, "term": Refusal.hit}`，分型三值为 `injection_refused`／`outbound_refused`／`write_refused`；步状态＝`refused`；
  - 直答收口：草稿＝`Refusal.content`、草稿类型＝`"direct"`（终稿就是那句话术）；
  - 过程档案一条（相位＝`understand`、标题＝步标题、摘要＝话术）。
  **本块零发帧、零写**——写口归公共簿记块、帧面归传输块。
- **它不碰谁**：不调模型（**连模型出口块都不 import**）；不引框架（纯字符串处理零依赖）；不引其余运行期块（**只许 import 状态块**）；不引引擎；不碰台账／术语表；零审计写入。
- **一个容易混的同名**：本块的 notice `type="refused"` 是**入口拒答**；作答块的缺口 `kind="refused"` 是**子问题级拒答**——**两者不同物，勿混**。
- **它在图里的位置**：

```
用户一句话
   │
 gate（本文这块：三族词表早退；命中 → 固定话术拒答收口）
   │
读题块（未命中才继续：读懂 + 定路线）
```

## 三、关键行为逐个讲

规格的「行为约定」共 15 条。

**行为 1｜三族闭世界＋先命先断。** 规格：判定序固定＝**注入 → 外发 → 写意图**；**第一命中即返**；三族皆未命中 → `None`（闸静默）。人话：按固定次序查，撞上哪族就按哪族返，不再往下；比如一句话同时像注入又像写意图，判成**注入**。

**行为 2｜注入族判据（逐字迁移）。** 规格：五条模式**大小写折叠子串**匹配；命中 → 返回**列表序首个命中的模式原形**（槽值）。五条模式逐字：

- `忽略之前`
- `忽略你之前的`
- `无视之前`
- `ignore previous`
- `ignore all previous`

人话：句子（不分大小写）里出现这几条里的任意一条就算注入，返回的是第一条命中的那个词本身，拿来填话术里的槽。术语：「**折叠**」＝比对前把大小写统一；「**槽值**」＝话术模板里要填进去的词。

**行为 3｜外发族判据（逐字迁移）。** 规格：动词（七条）× 通道（八条）**同问句共现**（子串；**不折叠**）才命中——单一词面不拦（降误伤）；命中 → 返回**列表序首个命中的通道词**（槽值）。词表逐字：

- 动词七条：`发到`｜`发送到`｜`发送给`｜`发给`｜`推送到`｜`传到`｜`外传`
- 通道八条：`邮箱`｜`邮件`｜`微信`｜`短信`｜`手机`｜`钉钉`｜`飞书`｜`外部系统`

人话：必须**又有动词又有通道**才算外发；只说「发到」或只说「邮箱」都不拦。命中时返回的是那个**通道词**（比如「邮箱」）。

**行为 4｜写意图族判据（逐字迁移）。** 规格：动词（十条）× 对象（六条）共现才命中（**对象按列表序取首个命中者**）；命中 → 返回**对象词**（槽值；**动词分量不携**）。词表逐字：

- 动词十条：`下调`｜`上调`｜`调到`｜`调成`｜`改成`｜`改为`｜`写入`｜`删除`｜`停用`｜`启用`
- 对象六条：`配注`｜`配产`｜`计划产量`｜`指标`｜`台账`｜`数据`

人话：既要有改动的动词、又要有所改的对象才算写意图；返回的是**对象词**（比如「配产」），动词那一半不往外带。

**行为 5｜匹配方式三族面（迁移照抄）。** 规格：**注入折叠、外发／写意图不折叠**（纯子串）——三族不齐＝V1 事实面（统一折叠＝规格变更）。人话：只有注入那一族比对时统一大小写，另外两族就是老老实实的子串比对；这个不一致是照旧迁过来的，要改得走规格变更。

**行为 6｜拒答话术三条逐字＋槽填充。** 规格：注入模板的 `{feature}`＝命中模式词原文；外发话术固定（无槽）；写意图模板的 `{target}`＝命中对象词原文；三条文本逐字（承载位换、文本不变）。三条逐字如下：

- 注入（`{feature}` 填命中模式词原文）：
  > 我注意到这句话包含「{feature}」——这类要求不会被执行，平台规则不可能被对话内容覆盖。
- 外发（固定，无槽）：
  > 本系统只读——未配置外发通道，数据不能发往邮箱、微信等外部渠道；可在本对话内查看，明细类结果可按行导出文本。
- 写意图（`{target}` 填命中对象词原文）：
  > 本系统只读——不做任何写入或调整，「{target}」等生产参数不在本平台变更；如需变更请走线下变更流程。

**行为 7｜命中＝早退（零模型零执行）＋收口信号。** 规格：命中 → 入口在**任务书装配与模型调用之前**早退（前置即断、模型看不到）。信号形状见第二节（notice 恰三键／步分型／直答收口／过程档案）。人话：命中就立刻停，模型压根不知道有这条问题；收口靠一句固定话术，并留下上面那几样可查痕迹。

**行为 8｜步标题三形逐字（迁移照抄）。** 规格：

- 注入 → `N0 注入拦截硬终止`
- 外发 → `N0 外发拦截硬终止`
- 写意图 → `N0 写意图拦截硬终止`

人话：三种早退各有一个固定的步骤标题，**逐字照抄**。「`N0`」是照旧迁过来的字面——**那套编号体系本身不进 V2**，**改名＝规格变更**。

**行为 9｜A 类问句零误伤＋收窄口径。** 规格：零误伤判据＝A 类问句语料**逐条过三族全 `None`**（以迁移钉测语料为准，**实存 20 条**逐条承接；票面 23／自检面 14 系前扩容口径——三口径差登记在案）。收窄口径＝①命中须动词＋通道／对象**共现**（常见单字面不拦）；②注入为**固定短语**（非泛词）；③**不靠扩词表覆盖间接／元问表达**——漏判由执行层兜；**不新增豁免机制**（V2 零豁免）。人话：正常业务问句不能误伤；判据收窄到这三种做法；**并且如实承认：这三条只是把 V1 已有的判据写进规格，净收窄为零**——像「删除的数据还能查到吗」这种共现形残留样本按**已知接受态保留**、登记在案；真要收窄得 Owner 另裁。

**行为 10｜词表闭世界、只扩不删、单点。** 规格：三族清单＋三条话术为闭世界常量；**只扩不删**（扩容随红队用例回流，扩条目须同批改本规格）；runtimev2 面内各**恰一处**定义、消费方零副本。人话：这些词只许往后加、不许删；全仓只此一份，消费方不许自己抄一份。

**行为 11｜`Refusal` 形状与越界行为。** 规格：三字段 `{family, hit, content}`；`family` 闭世界三值；`hit`＝槽值非空；`content`＝话术逐字非空；**越界构造＝判失败**（不猜、不取默认）。人话：返回的拒答对象就三个格子，每个格子都有底线要求，越界直接判错。

**行为 12｜确定性纯函数、零副作用。** 规格：同入参两跑输出相等；**零 I/O、零模型调用、零时钟、零随机、零事件发射、零状态写**；**命中路径零台账接触**。人话：这是一个「给文本、还结论」的纯计算器，不碰硬盘、不看表、不掷骰子、不发消息、不写状态。这里有个**重写不复刻的旧毛病**：V1 命中时会「当场再取一次词典层缝并写回」——那是**没人读的无效 I/O**（现状缺陷），新版直接不做。

**行为 13｜本块零语义判断。** 规格：不做豁免／元问／引用形判定；不判「提及 vs 执行」（已移出）；词表只作**明显命中的结构早退**（非判据）。人话：这块里不许有任何「猜意思」的代码。

**行为 14｜定位＝辅助快路径、非防线。** 规格：命中即不放行是**快路径早退**，**不是防线**；漏判由执行层兜（系统没有写／外发工具、只读连接＝结构保证）。人话：别指望它当安全防线——它是省一次调用的快捷方式；真正的安全靠「系统压根没有写和外发的工具」。

**行为 15｜废弃词闸不落本块（防写回门口）。** 规格：本块不定义 `apply_term_verdict`、不定义 `Disposition`、不读台账／术语表、不判「提及 vs 执行」——判断＝工具匹配块模型产出、分派＝前置检查块判定序第 1 位。人话：那个「旧口径是提到还是真要用」的闸整体搬走了，本块连它的符号都不许出现。

## 四、施工时要注意的坑

（以下是规格红线、风险与登记项的口语版。数字、上限、闭世界取值逐字不动。）

- **合法降级路径：无**——本块不降级：判定恒两态（`Refusal`｜`None`），**无半成品、无默认族、无「疑似」形**；未命中＝静默放行（**漏判不是降级面**——由执行层兜）。
- **命中必留机读信号（信号义务、发射面分工）**：notice `type="refused"` ＋ 步分型 ＋ 过程档案——信号**形状**由本块锁定，**发射与落账是消费方的义务**（写口归公共簿记块、帧面归传输块）；本块零 emit、不冒充覆盖。
- **本块零截断**：话术全文出、不改写、不缩措辞（槽值＝命中词原文，不截断）。
- **字面迁移要逐字**：词表／话术／步标题照抄，「`N0`」是迁移字面、编号体系本身不入 V2。**五个差异点**（这是迁移之外的全部改动，供逐字比对）：①收口步载荷分型键改名（`n1_gate` → `gate`）；②写意图命中槽值只携对象词（动词分量弃）；③命中路径零台账 I/O；④步载荷增 `term` 键（＝命中槽值）；⑤步状态＝`refused`（V1 恒 `ok` 是旧态）。
- **`Refusal` 构造越界要 fail-closed 抛错**（`family` 非三值／`hit` 空／`content` 空）——不猜、不取默认。
- **入参纪律**：纯文本进出、无时钟、无随机、无 I/O、无模型；**无数值面**（本块词汇表外没有任何额度／帽参数）。
- **单点纪律**：三族词表、三条话术、步标题映射在本 runtimev2 面内各恰一处定义；**消费方在相位块里私建同源副本（自写词表／话术字面）＝判失败**（V1 的旧毛病就是注入词表两份并存、可各自演化且无防漂移断言）。
- **限制与登记项**（如实说「还没定／只登记不改」）：
  - **A 类语料条数有三口径（23／14／20）**，**以钉测实存 20 条为准**——差异登记在案。
  - **收窄标准**没有 Owner 逐字条款；落地三做法见行为 9，**净收窄为零**，「删除的数据还能查到吗」这类共现形残留样本按已知接受态保留，真实收窄＝Owner 另裁面。
  - **卡级张力四件**（只登记、不改卡，交主窗回阶段 2）：卡面公开接口仍列着已移出的 `apply_term_verdict` 一行、卡面 Seam 行是移出件遗物、卡面未列族成员（常量族＋`Refusal`）、卡面测试计划行第二句是移出件遗物。
  - **理解相位的收口承接缺口**：理解块认「入口安全阀归 gate」「只消费其结论」，但**没有收口行为／验收行**——回提登记（补承接，或裁定落编排块）。
  - **消费方「只经包根」这半面无专属闸**：边界契约实建九块、不含本块的深层子模块面（设计注记本意是十块全护）——登记回提补闸，降维＝机器扫源码断言（待补）。
  - **零模型调用／依赖白名单（只许 import 状态块）没有专属闸**——降维＝机器扫源码断言 ＋ 人审。
  - **faq 五站链那条钉的「零落点」＝已裁定**（正确状态、非缺陷），本块知悉不挂。
  - **本块占位 docstring 残留**（旧双件定界）——阶段 5 施工同批改述，登记。
  - **链尾收口时点**：主链规格没明写——随上面对账登记。
