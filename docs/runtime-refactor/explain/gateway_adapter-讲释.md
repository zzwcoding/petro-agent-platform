# 网关桥块讲释（人类阅读版）

> 日期：2026-10-16。写给人看——没跟过工程的人也能读懂；给机检看的断言一条都不在这里。

## 一、这块是干嘛的

系统要动脑，就得把问题交给大模型（以下简称「模型」）——但模型不是自家的，是通过一家供应商的接口用的。**网关桥块就是「叫模型」这件事的唯一闸门**：谁都不许自己接供应商，所有模型调用都必须从这道门过。门这边是本系统的规矩，门那边是供应商和路由的细节——**供应商与路由细节不出这道门**。

它管四件事：①一次调用要交什么（入参面）②模型答回来什么形状（回执面）③被限流或超时了怎么重试等候（限流重试与退避）④测试时用什么替身、评测时用哪一天当「今天」（测试替身与评测冻结时钟）。

术语解释：**回执**＝调用完交回来的那张结果单；**退避**＝重试之前先等一小会儿，而且越失败等得越久，避免把对方挤垮；**替身**＝测试时顶替真模型的那个假货，行为一致但不联网；**冻结时钟**＝评测时把「今天」定死成某一天，否则每次跑结果都不一样。

一句话记住它：**模型调用的唯一闸门：只转发与记账，失败就抛，不编话术。**

## 二、它和邻居怎么打交道

一句话：它**向下依赖基础设施块的供应商出口、时钟与原始失败事实**，然后**只向簿记块交出「发起调用」的桥面**。

- **谁给它料**：基础设施块——模型的唯一供应商出口、时钟、以及**原始失败事实**（异常类型、状态码）。注意规格的一条分辨：本块**摄入并映射**这些事实，但**不复用它的判据**（原因见行为 7）。
- **它给谁用**：
  - **簿记块**：它是**唯一的发起方**——节点侧要调模型，都通过簿记块的单一入口 `call_model`，由它来调本块的 `complete`；本块把回执的**用量与归因面**（谁调的、属于哪次运行、用了多少 token、缓存命中多少、实际服务别名、耗时）交出去给簿记块记账并写进材料清单。
  - **编排块**：调用失败的收口归它——把失败转成「运行失败」的通知，然后正常收束。
  - **测试与评测**：替身与冻结时钟由本块提供。
- **它不碰谁**：不装配提示词（那是提示词块与簿记块的事）；不决定「何时调用、调几次」（那是编排与各相位的事）；不落盘调用记录（记录的落盘路径在基础设施块内部，本块只传归因面）；不引包里其它运行期块（只依赖基础设施块）；不直引检索引擎。
- **它在图里的位置**：

```
基础设施块（供应商唯一出口、时钟、原始失败事实）
   │
gateway_adapter（本文这块：调用桥 + 回执 + 重试退避 + 替身 + 评测时钟）
   ▲
   │ complete(messages, caller, run_id)
bookkeeping.call_model（节点侧唯一发起单点）→ 各相位节点只拿 content
```

## 三、关键行为逐个讲

**行为 1｜唯一出口＋桥接单点。** 规格：运行时内所有模型调用都经本块的 `complete`；发起方是簿记块的 `call_model` 单点，其余相位不得自行发起；桥接规则＝`call_model` 从状态取 `run_id`，以 `(messages, caller, run_id)` 调本块，**向节点只回 `content`**，而回执的用量与归因面交给簿记块记账并进材料清单。人话：全系统只有一个地方能按门铃（簿记块），门铃按完只把「模型说的那句话」交给干活的节点，至于「花了多少钱、谁花的」另走记账线——别让一句裸文本把账目吞了。为什么：规格写明「别让裸文本吞掉记账面」。

**行为 2｜入参面固定三件。** 规格：`messages`（消息序列）／`caller`（关键词）／`run_id`（关键词）；**无自由 `params`**；传未知键报错。人话：进门只许带三样东西——要说给模型的话、谁在说话、属于哪次运行；不许顺手塞「供应商参数」之类的私货。为什么：规格把「自由参数透传」明确列为**本块不做的事**——调参在本块内单点，不对外开自由键。

**行为 3｜回执面恒全键。** 规格：十个字段**恒在场**（失败尝试时 `error` 非 None、`content` 为空串）；`cached_tokens` **上游未上报时 =0**（不缺口、不省略）。人话：结果单永远十个格子一个不少——失败也要交单，只是正文空、错误格填上；缓存命中数上游没报就写 0，绝不留空。为什么：规格把「缺口或假值」列为风险；另有一条已知事实——**现用上游（MiniMax 面）不上报该字段**，所以 =0 是常态而非异常。

**行为 4｜异步是硬要求。** 规格：`complete` 是协程（真实 I/O）；不得在事件循环内同步阻塞调用。人话：叫模型是慢活，必须用「等的时候让别人先跑」的写法，不许把整条流程卡死。

**行为 5｜归因面逐调用保留。** 规格：每次调用都把 `caller` 与 `run_id` 交给出口，**逐调用不合并、不覆盖**；`caller` 取值来自调用方（**四桶族：理解／决策／作答／回炉**——第四桶 `repair` 为 2026-10-19 V2-125 新增，回炉修复轮的调用此前混在作答桶里）。人话：每一次调用都单独盖两个章——「谁问的」和「哪次运行」，不许把多次调用揉成一条。

**行为 6｜重试只对可重试类。** 规格：限流／超时／网络错／5xx → 按配置的重试次数与退避重试；**4xx 业务性拒绝不重试**（不误伤）。缺省值以现状环境变量的两个键为**现状锚**（可被环境覆写），**正式数值阶段 5 随真机定，本规格不复制字面值**——也就是说，重试几次、等多久，**具体数值还没定**。人话：对方说「你太快了」「超时了」「网断了」可以缓一下再试；对方说「你这请求本身不对」就别试了，试一百次也一样。

**行为 7｜可重试性的判据在本块成闭世界，且与「切备」分层（两件事，不许并成一句）。** 规格：合法失败类别＝`rate_limited`（429）｜`timeout`｜`upstream_unavailable`（网络错／5xx）｜`rejected`（4xx 业务性拒绝）；**可重试＝限流／超时／网络错／5xx**（三类：`rate_limited`／`timeout`／`upstream_unavailable`）；**不可重试＝`rejected`（4xx 业务性拒绝）**——2026-10-16 随规格改批同步（流水 53-D，与行为 6 对齐）。分层辨明：基础设施侧的现状判据回答的是「**要不要切备用部署**」（网络错／超时／5xx 可切；**429 不可切**——换部署救不了请求本身）；本块回答的是「**同一个调用要不要再试一次**」——**429 可重试**。两者判据方向不同、都不是对方。人话：四类失败里只有「限流／超时／网络错（含 5xx）」这三类够格重试，4xx 业务性拒绝不重试；另外要分清两件容易混的事——「换个服务器再来」和「同一个请求再试一次」是两个不同的问题，答案甚至可以相反（429 不该换服务器，但可以原地再试）。规格同时登记了一个**跨块待办**：把供应侧的失败分类**单源化**（归基础设施块规格侧）——本块只做摄入＋映射，不新造第二张阈值表。

**行为 8｜重试耗尽 fail-closed。** 规格：重试耗尽或不可重试类 → **原异常上抛**（不返回空应答、不静默降级为「无材料」），收口归编排块。人话：试到头还不行就把错误照原样抛出去，绝不假装「没查到材料」——那是编故事。术语：**fail-closed**＝出错就按失败处理并停住。

**行为 9｜评测冻结时钟。** 规格：解析规则逐条——环境变量**未设或空串 → 缺省冻结日**；**`real` → 当日真实日期**（读基础设施的时钟；**必须显式指定**，不得默认走真实钟）；**ISO 日期 → 该日**；**非法值 → 抛错**（fail-fast，不静默回落）；**生产装配路径不得读该环境变量**（只经显式注入缝）。人话：评测时的「今天」按四种规则解析：不设就用缺省的冻结日、写 `real` 才用真正的今天、写日期就用那一天、写别的就报错；而且**生产环境根本不许去读这个开关**，必须显式传进来。规格说明这一取向是**对现状的有意收正**（现状在 `real` 时返回空、交调用方另取钟，两处判据容易漂移；本块统一为「恒回一个日期」）。

**行为 10｜用时与用量如实。** 规格：`duration_ms`／token 计数实测（非估算时 `usage_estimated=False`）；**估算必须显式标注**（不许把估算当实数——`usage_estimated` 就是那个机读信号）。人话：花了多少时间和多少字，要么是真的，要么明确标「这是估的」；估的不能当实数去计费。

**行为 11｜替身与生产桥同面。** 规格：测试替身 `ScriptedCompleter` 的 `complete` 与生产桥**同形签名**（替身 `run_id` 可缺省＝测试便利，生产面必填）**与同一回执形状**，离线零触网；观测面 `calls`／`counts()`／`messages_of()` 只读留痕（`calls` 为公开留痕属性，**测试断言专用**）、**不改注入剧本**。人话：测试用的假货必须和真货长得一样、答得一样形状，这样测试才有意义；看假货的账本是只读的，不许顺手改剧本。现状事实：替身那一件的 14 个测试已全绿。

**行为 12｜替身不静默兜底。** 规格：未剧本化 caller 且未设 `default` → **当场抛错**（不静默返回空串）；设了 `default` 则照回且**调用照样留痕**。人话：假货没排练过这个场景就老实报错，别默默给一句空话；若事先配了兜底答法，那就答，但这次调用一样要记在账上。

**行为 13｜本块零判断。** 规格：不读词表、不判语义、不做业务分支（只有「可重试／不可重试」这类由基础设施判据给出的结构分派）。

## 四、施工时要注意的坑

- **合法降级路径＝无**：调用失败＝原异常上抛，由编排块收口成「运行失败」通知；**不得**把失败静默改写成「无材料」「未找到」这类业务话术。
- **失败必须留痕**：失败尝试同样产出回执（`error` 非 None）且同样进记账归因面（`caller`／`run_id` 齐备）——留存条数＝尝试次数。
- **估算必标注**：`usage_estimated` 不得恒定值——估和实测两条路径取值必须不同。
- **冻结时钟不得静默回落真实钟**：`real` 必须显式；未设环境变量时取缺省冻结日（≠ 真实当日）。
- **模型供应商唯一出口＝基础设施块**：本块是全工程**唯一允许**直引该出口的运行期块；**不许自建 HTTP 客户端／供应商 SDK 直连**（绕开出口就是违规），对应机器闸只覆盖「唯一接触点」这一面，另一半靠静态断言＋人审。
- **回执只有一个定义**：现阶段该回执类型暂寄居在替身文件里（织网地基先行），**唯一定义**；阶段 5 迁到非替身模块后由替身 import——**不许两处各定义一套**。
- **`alias` 语义**：服务别名由路由决定并**随回执返回**，调用方不再传（现状生产传空别名、替身缺省别名两处不同源，本块收正）。
- **已知未定／登记项（照实说：还没定）**：
  - 重试**次数与退避的正式数值阶段 5 随真机定**，本规格不复制字面值（现状环境变量只是**现状锚**）。
  - **调参面缺失**：当前没有按 caller 调参的对外键；将来若要加，**属规格变更**（须同批改接口与卡）。
  - 「供应侧失败分类单源化」是**跨块待办**，登记在基础设施块规格侧——本块不认领。
  - 有一条历史钉子写的「帧里 `frozen_date` 全在场」半面：经码面取证，`frozen_date` 只出现在**评测跑批记录**里（不是网页帧）——该半面**不属本块**，建议改准原钉文措辞，**呈主窗**。
  - 「调用记录落盘」的落痕面归基础设施块规格侧，**登记待补**——本块只传归因面，**不冒充覆盖**。
