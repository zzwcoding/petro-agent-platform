> **本文是派生视图，不是真源。** 真源＝`specs/agent-loop.md`（已定稿）。
> 规格改，本文即废；本文与规格冲突，以规格为准。
> 日期：2026-10-16。写给人看——没跟过工程的人也能读懂；给机检看的断言一条都不在这里。

## 一、这块是干嘛的

用户在问一问页提一个问题（打到 `/api/v2/chat/asks`），系统要**自主地**把这个问题查清楚、答出来。**编排块就是「驱动这一整条主链路」的那一块**——它不干具体的读题、选工具、查数，它负责**把各个相位串成一条有界自主循环、把事件流发出去、把挂起与恢复管起来**。

它的三个关键词：

- **有界自主循环**：一轮＝四个相位（业务澄清 → 工具匹配 → 前置条件机 → 批量执行＋汇总）；整个循环**每个用户输入周期 ≤3 轮**——轮 1 得部分答案，轮 2/3 只带失败／缺失的子问题回炉。**有界**就是说它绝不会无限跑下去。
- **语义与判定分工**：**LLM 出语义**（澄清／分解／提议），**代码出判定**（前置条件机零 LLM）。
- **全程可见、可挂起、可恢复**：全程有事件流可看；答案带 fail-closed 引用（借不到材料就不硬说有据）；中途可以澄清或审批挂起，之后能恢复继续。

**为什么只有它允许用框架**（LangGraph）：这条主链本质是一张**状态图**——有节点（各相位）、有条件边（往哪跳要看结论）、有路由表、还要**检查点**来支持挂起与进程重启后恢复。图执行与检查点这套机制自己重写一遍，会和业务相位的逻辑纠缠在一起，容易写歪。所以规格把框架限缩在**图执行这一层、只许活在本模块内部**：

- **`LangGraph`（含 `langchain*`）不得渗漏出本模块**——其余 16 块一律禁引（机器闸守）；
- **状态结构自有**（`RunState` 是自有数据结构，框架只当 schema 消费，不去接管状态的形状）。

人话：框架是请来当「图执行器」的，只许待在这一间屋子里，别的地方谁都不许用。

一句话记住它：**唯一许用框架的块：四相位循环、挂起可恢复、到顶有界终止。**

## 二、它和邻居怎么打交道

一句话：它**受理用户请求**，**驱动四相位**，然后**以事件流的形式把过程与结果交出去**。

- **谁给它料**：
  - **接口层**：三端点的请求与身份（身份经基础设施层的身份缝解析）。
  - **状态块／存储归档块**：状态形状与持久化（检查点、三态落库）。
  - **上下文块**：对话状态簿记（`dialogue` ＋ `process_notes` 双字段）。
  - **工具块**：经统一注册表调五个工具（只消费公开接口）。
- **它给谁用**：
  - **接口层**：事件流（首帧 run_id；九类事件闭世界：**step／text／tool／observation／ask／verdict／citation／notice／blackbox**）。
  - **各相位**：编排层把路由表集中在自己这里，相位不自行决定跳转。
  - **传输块**：发帧只经传输块**包根**，不自行拼 wire 帧。
- **它不碰谁**：不直引模型出口（模型调用发起只经公共簿记块统一窗口）；不直引引擎（知识库／查询／检索只经工具块公开面）；不替模型判语义、不替前置检查块做闸。

## 三、关键行为逐个讲

规格的「行为约定」共 11 条。

**行为 1｜四相位循环。** 规格：每问新建 run，读题理解后进四相位——

①**业务澄清（clarify）**：LLM 带 Skill 指南发射**四动作**闭世界 `discover｜decompose｜ask｜finalize`；`discover`＝钻取（semantic_query／doc_retrieve／table_schema）；`decompose` 产出**问题组**（子问题含 id／question／ledger_notes／chain，**已去掉 tool**——选工具归②匹配相位）；子问题上限 **≤4**；`ledger_notes` 必填——形＝「槽位｜绑定态｜窗」**三段槽位对账**（段一逐字∈台账名录∪「无台账命中」（无台账行的报告内容题——自造名不算）、段二∈闭世界「已绑定/未绑定」、段三＝锚定窗或「窗未定」或同义形「无时间窗」或双 null 发射形）；`ask`＝反问挂起。

②**工具匹配（toolmatch）**：LLM 逐子问题提议工具／链（data→data_query、knowledge→doc_retrieve，data 链必带 plan、knowledge 链必带 retrieval_need），与问题组**闭世界对账**（组内每子问题恰一条匹配，缺／多／未知 id 均拒）。

③**前置条件机（precondition）**：**纯固定代码零 LLM（铁律——LLM 无权判定）**，逐子问题过闸判**三态**：`allow`｜`refuse`（子问题如实拒答）｜`ask`（挂起）；注记并入放行，**不设第四态**；闸项＝**8 个判定位**。

④**批量执行＋汇总（batch）**：子问题组执行＋观察汇聚，LLM 整合全组子结果（逐子问题引用）→ 核验收口。

每步落 step 记录：**类型六值闭世界** `decision／discover／execute／observe／verify／answer`；相位以载荷里的 `phase`＝`clarify／toolmatch／precondition／batch` 标注；审计责任账走唯一写口。

**行为 2｜每步在 `messages` 整链续写。** 规格：每个 LLM 调用发送**整条链**（＝上次链＋尾段），模型应答与过程记录以类型正确的消息**追加链尾**，任意相邻两次调用互为前缀延伸；对话状态**双字段**：

- `dialogue`——自然对话层（用户原话／助手终稿／澄清审批回收原文；**禁**任务书／指令／过程原话／注记前缀）；
- `process_notes`——过程档案层，条目形 `{phase, title, digest}`，**digest 每条 ≤200 字**。

执行台账以「参数 → 结果：N 行／闸拒（拒因）」形落 `process_notes`。历史增长超窗时的压缩＝**compaction**（**只压模型视图、原史零覆盖**），披露账目显式进 Manifest。词典层**每轮常驻注入**（台账全量＋别名＋结构卡直接编进上下文，Manifest 记来源行），常驻块随当轮渲染、**不入史防 token 放大**——「开局已给全台账，禁猜词敲门」。每次调用产出 **Manifest** 随 step 存档。
人话：给模型看的是一整条不断往后接的对话链，**只能追加、绝不改写前缀**；「工位指令、过程记录」和「人和助手的真话」分两层放；过程摘要每条不超过 200 字；历史太长时只压缩「给模型看的那份」，**原始历史一个字都不覆盖**。

**行为 3｜发射判据。** 规格（**判断在模型侧产出、程序只按结论分派，本行为不入程序验收面**）：窗可锚定＝禁 ask；时间词按窗词锚定表可解析即锚定发射，无时间词 → 默认近 30 天 ＋ 注记；台账命中 ＋ 窗已定＝禁再 discover（直发分解）；ask 仅限两种白场（无场景词＋阈值判断形的口径反问、目标／对象／口径真歧义）；越集 → 审批。schema 校验失败＝**拒因回喂重发射，无 repair**（不做自动修补）；同参重投闸落执行块；本块保留轮数闸／自旋收敛的预算面层。
人话：什么时候该问、什么时候该直接分解，是模型的判断；程序只按结论办事。格式不合格就把理由退回去让它重发，**绝不自动修**。

**行为 4｜工具调用与挂起。** 规格：工具只经统一注册表调用；返回 `status=ask` 时 run 转 `waiting_ask` 挂起，事件流发 ask 帧后正常收束；`resume` 带选择续跑（全程只读）。外表越集审批态落在「工具上下文」的批准表里（**不走引擎自己的批准表、不重排计划**）；前置条件机的 `ask` 态与引擎侧 ask 同走**挂起—恢复链**。

**行为 5｜核验收口。** 规格：逐条检查草稿的断言有 Observation 支撑；无支撑断言改写为「未找到／材料未披露」并出 notice——**禁止无据断言进答案**（表格行／血缘卡／片段承载豁免按既有口径继承）。

**行为 6｜`caliber_key` 三态。** 规格：场景词（月报／正式／化验）→ 确定性匹配口径支；无场景词＋取数形 → 双口径并列（血缘卡两支同载）；无场景词＋阈值判断形 → 反问（用户已答才代选）。计划带 `caliber_key` 做合法口径校验，查询计划域面零改动。

**行为 7｜预算闸（触界即收敛）。** 规格：触界时交付已取得观察材料（未核实的直排标注「未及核验」，**非断言不违反红线**）＋ notice 明示未完成项，**不得静默截断**——

- **轮数**：每用户输入周期 **≤3 轮**（轮＝LLM 决策周期；clarify 发射 discover 钻取**不占轮**，decompose **占轮**；ask 挂起等人工**不计轮**；澄清回收（resume）**重置轮预算**合法——rounds=0）；轮 2/3 只带失败／缺失子问题＋拒因回炉①，**成功子问题结果保留不重跑**；
- **发现预算**：全 run discover **≤10**（Owner 拍板放宽原 3-4）；预算拒免轮例外**只留首次**——连续第 2 次起转占轮（自旋收敛闸）；
- **单段时限 300s**（挂起等人工不计时、不累计跨段——计步计时均按段）；
- **单工具超时 30s**；
- **discover 计数埋点**：每次钻取落 step 载荷（次数／查询词指纹／命中数／命中形态 `no_hit｜rows:N｜empty`）供跑批分析。

人话：跑飞有硬上限兜住——最多 3 轮、整个 run 最多 10 次钻取、单段 300 秒、单个工具 30 秒；**到顶不是「装作答完」，而是把已经拿到的东西交出去并明说没做完的部分**。

**行为 8｜执行器与命令入口＋图装配与路由。** 规格：

- **命令受理**：`ask`／`resume` 是唯一入口——**命令 → 执行器 → 事件**为显式接缝（将来换队列消费者，接口／工具／事件契约零改动）；
- **图驱动**：组合图执行由本块驱动（命令进、事件流出），**业务相位不自驱**；
- **三态落库**：`completed`／`failed`／`waiting_ask` 三态**由本块写 run 表**（答案与 Manifest 摘要随三态落）；
- **审计接线**：受理／三态收口／拒答收口／外表审批决定／禁用词豁免**五处留痕**都经审计唯一写口落责任账——**计数口径以「action 闭世界七值」为准**（三态收口＝完成／失败两值、审批决定＝批准／驳回两值），**本处不写类数**（旧「四事件」说法已废——它漏了禁用词豁免）；action 恒 `agent_v2.*` 前缀；
- **身份缝**：请求身份经基础设施层的身份解析函数解析（开发期身份桩；正式接 OAuth2.0 **只换该函数实现，其余零改动**）；
- **组合图装配与路由表**：节点注册、条件边、路由表在本块**一处集中**——**业务相位不得自行决定跳转**。

**行为 9｜run 状态机。** 规格：`running → waiting_ask →（resume）→ running → completed/failed`；引擎事件外置持久化，断线凭游标续传，**进程重启后可恢复 `waiting_ask` 态**（resume 可达）；追问（`followup_run_id`）＝会话线程新轮——前轮消息历史（含问答／执行台账）随追问进新 run 上下文，**前轮须 `completed`**（错误在开流前用 404／409 包）。

**行为 10｜`run_id` 全盖章。** 规格：每个 run（及其子问题）盖 `run_id`，逐题的 run_id 集合与账本的 run_id **等值**（计费可逐题对账）。

**行为 11｜`verdict` 帧两形的批次落定。** 规格：`verdict` 帧有 `verify`（核验裁决）与 `final`（收口）两形；**两形的发帧时机与批次由本块协调**——核验块与作答块各自**只保证自产部分就位**，**由本块把它们与链尾收口按同一批落定**；两形缺任一同批判失败。

### 对外的接口与错误码（照抄）

- 公开接口：`ask(请求) → 运行句柄`；`resume(run_id, 选择) → 运行句柄`。
- 受理请求有**三形态**——①仅带 `question`＝提问；②带 `resume_run_id`＝断线重连；③`question`＋`followup_run_id`＝追问续会话（前轮须已 `completed`）。**②③互斥，同在场＝409**。
- 运行句柄＝`{run_id, stream, cursor}`，其中 **`cursor`＝全流单调的断线游标**（重放不位移）。
- 端点四行：`POST /api/v2/chat/asks`（200 → 事件流，首帧 run_id）｜`POST /api/v2/chat/runs/{run_id}/resume`（200 → 事件流）｜`GET /api/v2/chat/runs/{run_id}`（200 → 状态／步骤／Manifest 摘要／挂起帧投影）｜`GET /api/v2/chat/runs?limit=N`（200 → 最近任务列表，按创建时间降序）。
- 错误：**400** 参数非法｜**401** 身份缺失｜**404** run 不存在｜**409** run 非挂起态不可 resume（重连／追问互斥同 409）。

## 四、施工时要注意的坑

（以下是规格红线、风险与登记项的口语版。数字、上限、闭世界取值逐字不动。）

- **合法降级路径：无**——编排层不自降级；图执行器不可用时按 fail-closed **收束为 `failed`**，**不产出半成品答案**。
- **不许自述完成**：**模型只能「申请」完成，提交完成的是编排块**（依据核验结果）。人话：模型说了不算，核验过了才算完成。
- **三态落库、挂起、预算触界、审计都必须产生机读信号**：事件帧（九类闭世界）＋ step 载荷 ＋ 审计责任账。
- **触界不得静默**：预算到顶时交付已取得材料 ＋ notice 明示未完成项。
- **框架只在本块**：`LangGraph`（含 `langchain*`）不得渗漏出本模块，其余 16 块禁引（机器闸守）。
- **模型调用不许旁路**：只经公共簿记块统一窗口发起；不直引模型出口、不自建模型客户端；**只经工具块公开面接触世界**、不直引引擎。
- **发帧只经传输块包根**（不自行拼 wire 帧）——这半面**没有专属闸 → 人审**（登记待补降维断言）；**禁手写替代**（不得自建图执行器旁路／模型客户端／帧通路）同为「可降维面 ＋ 人审」。
- **路由集中**：节点注册、条件边、路由表在本块一处集中；业务相位不得自行决定跳转。
- **审计口径**：五处留痕都经唯一写口；**计数只以「action 闭世界七值」为准，旧「四事件」说法已废**（它漏了禁用词豁免）。
- **身份缝单一入口**：身份解析只经那一个函数；正式接 OAuth2.0 只换该函数实现。
- **换链回炉态**（一个容易看错的分支）：data 链＋指标在册（归一后）＋绑定闸拒（在册但未绑定汇总表）**自某次裁决起＝换链回炉态**——不直答不执行，携拒因＋改链提示＋「换链提议」标记回炉①澄清相位（复用失败子集回炉机制，**占一轮、不占 ask 预算／不挂起**），**一次为界**；坚持 data 链同参再触发＝**直答终局**（不环，同参指纹在换链标记簿记里）。
- **风险清单**（规格点名）：框架检查点的数据库 saver 与 V1 表共存（**新表前缀 `agent_v2_` 隔离**）；剧本化测试的假模型要按对话状态（双字段）形态驱动多轮重放；历史 token 预算截断策略失当会挤占词典层常驻块（**截断显式进 Manifest 可查**）。
- **不做什么**（规格明列）：不做记忆／跨会话个性化（追问续会话除外，那是会话线程承接，**不是**个性化记忆）；不做自进化；不做写操作（全程只读）；不动 V1 端点（本块只落 `/api/v2/chat/*`）；不替代引擎侧 citation 校验（本块核验是叠加、不替代）；schema 校验失败不自动 repair（拒因回喂重发射）。
- **还没定／登记在案的事**：
  - **十节标题齐备、逐字、有序**＝**人审**（仓内无标题闸；登记可降维为一条标题机检，本批未授权）。
  - **「只经传输块包根发帧」无专属闸 → 人审**（登记待补降维断言）。
  - **禁手写替代**：可降维面靠框架／模型出口两条机器契约，其余**无专属闸 → 人审**（登记待补）。
  - **相位合同一次性**、**挂起→resume 闭环**、**追问播种承接**、**`messages` 只追加**、**`run_id` 全盖章**这些是挂在测试网上的钉，本批以规格为准。

## 五、一句话记住它

**唯一许用框架的块：四相位循环、挂起可恢复、到顶有界终止。**
