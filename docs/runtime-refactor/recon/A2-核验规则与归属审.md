### `_parses_as_json`（L677-L682）｜文本是否可解析为 JSON 对象或数组
- 分支表（穷尽）：
  1. `json.loads(text)` 抛 ValueError → 返回 False。
  2. 解析成功且结果为 dict 或 list → 返回 True。
  3. 解析成功但结果为 JSON 标量（数字/字符串/布尔/null）→ 返回 False。
- 副作用：无。
- 返回：bool。
- 规则条目：
  - R-A2-01 仅 JSON 对象/数组判 True，JSON 标量判 False（发射形判定取 dict/list 口径）——条件：解析结果类型；动作：布尔判定；去向：调用方 `_fence_is_json`/`strip_emission_fences` 的剥除决策。
- 耦合：json（stdlib）。
- 疑点（只列不判，不静默）：
  - D-A2-01 只捕 ValueError：极端深嵌套 JSON 可抛 RecursionError 逸出本函数（无兜底）。

### `_fence_is_json`（L685-L694）｜围栏体是否 JSON 段（整段可解，或前缀噪声形首个 `{` 到末个 `}` 可解）
- 分支表（穷尽）：
  1. `body.strip()` 整体可解析为 JSON 对象/数组 → True。
  2. 否则取首个 `{` 与末个 `}`；两者存在且 `end > start` 且中段可解析为 JSON 对象/数组 → True。
  3. 其余（无花括号／花括号逆序／中段不可解析）→ False。
- 副作用：无。
- 返回：bool。
- 规则条目：
  - R-A2-02 围栏体判定宽口径：整段 JSON 或前缀噪声形（如散文行＋换行＋`{...}`）皆算 JSON 段（含发射形与否）——条件：可解析性；动作：判 True；去向：`strip_emission_fences` 整块剥除。
- 耦合：无（同文件 `_parses_as_json`）。
- 疑点（只列不判，不静默）：
  - D-A2-02 中段取「首个 `{` 到末个 `}`」：围栏体含两个并置 JSON 对象（`{...}` 换行 `{...}`）时中段整体不可解析 → 判非 JSON 段 → 不剥（整块保留）。
  - D-A2-03 前缀噪声形不校验「噪声」性质：首 `{` 之前的围栏内可读文字也在整块剥除范围内（说明文字随 JSON 段同去）。

### `strip_emission_fences`（L697-L736）｜确定性剥离答案文本中的 JSON 通道残留，返回（剥后文本, 是否检出）
- 调用：caller=verify_draft（L827，取剥后文本、丢弃 leaked 标志）；caller=answer_node 起草段（L3903 首稿；L3908 空稿时同相位重试一次重稿，leaked 聚合）；纯字符串处理零 LLM/工具调用。
- 分支表（穷尽）：
  1. 围栏块（`_FENCE_RE` 匹配）：group(1) 判 JSON 段（`_fence_is_json`）→ 整块替换为空串且 leaked=True；否则整块原样保留。
  2. 对围栏剥除后的文本逐行（`splitlines`）：
     a. 行内命中 `_EMISSION_TOKEN_RE` 且捕获 action 值 ∈ ACTION_KINDS（discover/execute/ask/finalize 四值闭世界）→ leaked=True，整行丢弃（行内其余文本一并离场）。
     b. 否则 strip 后以 `{` 或 `[` 开头且整行可解析为 JSON 对象/数组 → leaked=True，整行丢弃。
     c. 其余行保留。
  3. 保留行以 `"\n"` 重新连接，连同 leaked 标志返回。
- 副作用：无。
- 返回：tuple[str, bool]（剥后文本, 是否检出 JSON 通道残留）。
- 规则条目：
  - R-A2-03 围栏体为 JSON 段（发射形与否）→ 整块剥；纯散文围栏零误伤原样保留。
  - R-A2-04 行内含裸发射令牌（action ∈ 四值闭世界）→ 整行剥（回声行余文＝提示原文同属泄漏承载）。
  - R-A2-05 整行即 JSON 对象/数组（无围栏）→ 剥除。
  - R-A2-06 域外 JSON（action 值不在闭世界、且整行非纯 JSON）→ 原样保留（零误伤）。
  - R-A2-07 剥除为纯格式隔离，不计数、不进 INV-1 改写统计（语义由调用方持有）。
- 耦合：re（stdlib，模块级 `_EMISSION_TOKEN_RE`/`_FENCE_RE`）；ACTION_KINDS（本文件 L180）；json（经 `_parses_as_json`）。
- 疑点（只列不判，不静默）：
  - D-A2-04 `splitlines` 按通用行边界切分后以 `"\n"` 重连：`\r\n`、`\u2028` 等被归一为 `\n`，末尾换行丢失——返回文本行分隔形态可能与原文不同。
  - D-A2-05 裸令牌正则值后 `[^{}]*` 禁嵌套花括号：行首为回声文本＋嵌套装发射 JSON（如 `{"action":"execute",…,"payload":{…}}`）时，令牌规则与整行 JSON 规则均不命中 → 该行照留。
  - D-A2-06 先剥围栏再逐行扫：围栏紧贴前后文时剥除后两段文本直接相连（无补分隔符）；剥除结果不再做二次围栏残形扫描。
  - D-A2-07 leaked 仅布尔：剥了几块/几行、剥了什么不可观测，调用方只能记「检出」。

### `_supported`（L753-L773）｜断言级支撑判定（方向观察→行：被引观察的数值须在断言文本复述）
- 分支表（穷尽）：
  1. citation 不在 by_index（越界引标）→ False。
  2. 观察 locator.kind ∈ `_CARRIER_KINDS`（agg_row/lineage/fragment）：
     a. 零数值 token → True（纯文本卡恒过）。
     b. 任一数值 token 在断言文本中（子串）→ True。
     c. 零重叠 → False（引标贴无关行照改）。
  3. 非 carrier：
     a. 全部数值 token 均在断言文本中找到 → True；零数值 token → `all(空)`＝True（恒过）。
     b. 任一 token 缺失 → False。
- 副作用：无。
- 返回：bool。
- 规则条目：
  - R-A2-10 支撑方向＝观察→行：被引观察每个数值须在断言文本出现；行内来自问句语境的量（日期窗等）不查。
  - R-A2-11 carrier 豁免（agg_row/lineage/fragment）＝权威承载不做全数值复述，任一数值重叠即支撑、零重叠照改（R9 反例不回退）。
  - R-A2-12 零数值观察恒过（纯文本卡）；越界引标恒无支撑。
- 耦合：re（模块级 `_NUMBER_RE`，L262）；`_CARRIER_KINDS`（本文件 L268）。
- 疑点（只列不判，不静默）：
  - D-A2-10 数值匹配为子串包含（`"52"` 命中 `"1520"`/`"52.3"`），非数值边界匹配。
  - D-A2-11 支撑单向：断言中多出的、观察没有的数字不予检查——有据行内编造额外数字不被本判定拦。
  - D-A2-12 零数值观察恒过，语义充分性不查（文档自陈细化批可换更强实现）。

### `verify_draft`（L796-L895）｜草稿逐行断言级核验（剥发射残留→逐行支撑/重判/放行/改写→分源块→归属审块）
- 消费：实参 draft、observations、anchors（caller 传 `state.draft`、`state.observations`、`entity_anchor_tokens(state.question)`；本函数零直接 state 读取）。
- 调用：caller=verify_node（L3662）；纯确定性零 LLM/工具调用——无格式解析/失败兜底链条。
- 分支表（穷尽）：
  0. 入口：by_index＝{int(index)→obs}（重复 index 后者覆盖）；draft 先过 `strip_emission_fences` 取剥后文本、leaked 标志丢弃；cited=∅、rewritten=0。
  1. 行 strip 后为空 → 原样保留（continue）。
  2. 行含字面占位符 `[n]`（`_PLACEHOLDER_CITE_RE`）：
     a. bare＝剥 `[n]` 后 strip；cleaned＝原行剥 `[n]` 后 rstrip。
     b. bare 非空且其引标辖域全部支撑 → cited 收全部引标；行以 cleaned 保留。
     c. 否则 bare 窗内对齐（`_window_aligned`）→ 行以 cleaned 保留、不计 cited。
     d. 否则 rewritten+=1；改写为「未找到（材料未披露）：{bare}」。
     （注：行仅 `[n]` 时 bare 为空 → chunks_bare=[]、窗内判定必 False → 直接走 d。）
  3. 行无引标且无数字 → 原样保留（结构承载：标题/表头/分隔线）。
  4. 行有引标且全部辖域支撑 → cited 收全部引标；原行保留。
  5. 否则计算 bare＝剥全部数字引标后的整行：
     a. 行有引标且任一辖域空壳（`_scope_usable` 假）且整行文本对每个引标逐一判支撑全过 → cited 收全部引标；原行保留（修一）。
     b. 否则 bare 窗内对齐 → 原行保留、不计 cited（修二）。
     c. 否则 rewritten+=1；改写为「未找到（材料未披露）：{stripped}」。
     （注：本支也吞「无引标但有数字」行——该形必在 b/c 二择。）
  6. 尾部装配：
     a. text＝保留行以 `"\n"` 连接。
     b. `_contradiction_members(cited, observations)` 非空 → split=True，text 追加 `"\n\n多来源不一致——分源列明（禁止无出处调和）：\n"`＋逐支「[index] source：content」。
     c. anchors 为真值 → `_attribution_block(...)` 非空块存在 → text 追加 `"\n\n"`＋块；空块不追加。
     d. 返回 (text, rewritten, sorted(cited), split)。
- 副作用：无（emit/step/notice 全在 caller verify_node：step STEP_VERIFY、verdict、notice unsupported_claim/contradiction_split/attribution_split）。
- 返回：tuple[str, int, list[int], bool]（核验后文本, 改写数, 被引序号列升序, 是否分源）。
- 规则条目：
  - R-A2-16 核验入口先剥发射残留（strip_emission_fences 取剥后文本）；剥除不计改写、leaked 不外传。
  - R-A2-17 行级判定优先级：空行 → 占位符行 → 无引标无数字结构行 → 全支撑行 → 空壳重判 → 窗内放行 → 改写。
  - R-A2-18 无据断言行改写为「未找到（材料未披露）：<原文>」且 rewritten+1（INV-1——禁止无据断言进答案）。
  - R-A2-19 空壳辖域修一：任一辖域空壳时剥全部引标记号、用整行文本对每个引标逐一重判，全过即保留并收 cited（引标序号自身不作数，防自证）。
  - R-A2-20 窗内对齐修二：整行重判不过时断言全部数字窗内可寻 → 保留且不计 cited（放行只降改写数）。
  - R-A2-21 占位符行（[n] 串台形）剥占位符整行重判：支撑或窗内对齐 → 以 cleaned 形保留（对齐不计 cited）；均不过 → 改写（占位符不进答案面）。
  - R-A2-22 无引标且无数字的行＝结构承载，不进改写辖域（V2-23）。
  - R-A2-23 分源列明（INV-4）：cited 内同 subject 且值不同 → 追加分源块；池基于 cited（窗内放行的引标不入池）。
  - R-A2-24 归属审块仅在 crossed 非空且 anchors 非空时追加；不改写行、不计改写数。
- 耦合：`strip_emission_fences`/`_assertion_chunks`/`_supported`/`_scope_usable`/`_window_aligned`/`_contradiction_members`/`_attribution_block`（本文件）；re（`_PLACEHOLDER_CITE_RE`/`_CITE_RE`/`_NUMBER_RE`）。
- 疑点（只列不判，不静默）：
  - D-A2-17 占位符行在 bare 为空时改写产出「未找到（材料未披露）：」（空断言尾）——整行仅 `[n]` 的如实产出形。
  - D-A2-18 by_index 对重复 index 取后值（dict 覆盖）——观察序号重复时判定基准取最后一条。
  - D-A2-19 窗内放行的引标不进 cited：该行 [n] 不入分源池/归属审/引用块；citation 帧由 `_finalize`（L3746-3762）以答案文本 [n] 另行补——放行引标在「cited 集合/引用块/citation 帧」三处语义不同。
  - D-A2-20 分源池 subject 提取依赖内容含全角「：」——半角冒号或无冒号的观察不入矛盾分组（材料格式假设）。
  - D-A2-21 无引标有数字行可经窗内放行（C5b）保留：出数行无引标、不计 cited，答案面出现无出处序号的数字行。
  - D-A2-22 统计口径：重判/放行救回的行不计改写（改写数只降不升）——verdict.rewritten 是「改写行数」而非核验拦截面。
  - D-A2-23 空壳重判（C5a）把整行文本当作全部引标的共同断言体：辖域切分被放弃，每个引标须对同一整行全数值复述命中。

### `_attribution_conflicts`（L923-L946）｜归属审二分（cited 内检索片段 →（对齐支, 跨源支））
- 分支表（穷尽）：
  1. needles 为空（无锚或锚规范化后全空）→ 返回 ([], [])（审静默）。
  2. 逐观察：index ∉ cited → 跳过。
  3. index ∈ cited 且 locator.kind ∉ `_ATTRIBUTION_CARRIER_KINDS`（fragment/graph）→ 跳过（数据链行级/元信息不入辖域）。
  4. 对齐（`_observation_aligns` 真）→ 对齐支；否则 → 跨源支。
- 副作用：无。
- 返回：tuple[list[obs], list[obs]]（两列表均保持观察序，确定性）。
- 规则条目：
  - R-A2-26 归属审辖域＝被引检索片段（fragment/graph）；cited 之外零消费；无锚＝两空表零输出。
- 耦合：`_observation_aligns`（本文件）；`normalize_anchor_text`；`_ATTRIBUTION_CARRIER_KINDS`（本文件 L902）。
- 疑点（只列不判，不静默）：
  - D-A2-27 每次核验中本函数被调用两次（verify_draft 内 `_attribution_block` L959 一次、verify_node L3665 一次）——同一结果重复计算（幂等，纯重复）。

### `_attribution_block`（L949-L1006）｜跨源归属审块文本（分源列明或窗内无对齐如实说）
- 分支表（穷尽）：
  1. `_attribution_conflicts` → (aligned, crossed)；crossed 为空 → 返回 ""（全对齐零追加）。
  2. 重算 needles；uncited_aligned＝非 cited 且 kind ∈ {fragment,graph} 且对齐的观察（观察序）。
  3. 头行：「跨源归属审——分源列明（题眼锚：<anchors 原文、连接>；禁止无出处调和）：」。
  4. aligned 或 uncited_aligned 非空：
     a. aligned 非空 → 「对齐题眼锚：」＋逐支「[index] source：content」。
     b. uncited_aligned 非空 → 「对齐题眼锚的材料（在窗未进答案引用——按出处核对）：」＋前 `_ATTRIBUTION_LIST_CAP`(4) 支；余量 >0 → 「……另 N 支对齐材料从略（按出处核对）。」。
  5. 否则（窗内零对齐材料）→ 「窗内无对齐题眼锚（…）的材料——所引均为跨源材料，如实列明，不作题眼归属断言。」。
  6. 尾段「跨源引用（引标源与题眼锚不一致——按出处如实区分，不得并入题眼断言）：」＋逐支「[index] source：content」（crossed 全量，无上限）。
  7. 返回 `"\n".join(lines)`。
- 副作用：无。
- 返回：str（空串＝零追加）。
- 规则条目：
  - R-A2-27 跨源支在场才出块；块内对齐面三分（被引对齐支全列／在窗未引对齐支前 4 支＋余量计数／零对齐如实说无），跨源面逐支全列。
  - R-A2-28 窗内无对齐材料时声明不作题眼归属断言（跨源材料不冒充题眼证据）。
- 耦合：`_attribution_conflicts`/`_observation_aligns`（本文件）；`normalize_anchor_text`；`_ATTRIBUTION_LIST_CAP`/`_ATTRIBUTION_CARRIER_KINDS`（本文件）。
- 疑点（只列不判，不静默）：
  - D-A2-28 跨源支（crossed）全量列示无上限——`_ATTRIBUTION_LIST_CAP` 只辖未引对齐支，长窗跨源支多时块长随支数线性增长。
  - D-A2-29 题眼锚显示用原始 anchors（未规范化）拼接；匹配面用规范化 needles——显示口径与匹配口径不同源。
  - D-A2-30 uncited_aligned 为独立重算（对非 cited 观察再跑一遍对齐判定），与 `_attribution_conflicts` 的 cited 门形成互补但不共享结果。

### `_contradiction_members`（L1009-L1032）｜同 subject 值不同的被引观察（跨源矛盾池成员）
- 分支表（穷尽）：
  1. 逐观察：index ∉ cited → 跳过。
  2. locator.kind ∈ {"agg_row", "lineage", "notice"} → 跳过（行级时序事实与元信息不入池）。
  3. content 含全角「：」→ subject＝首个「：」前文本；不含「：」或 subject 为空 → 不入分组。
  4. 按 subject 分组；组内支数 <2 → 跳过。
  5. 组内「：」后原文集合去重后 >1 个值 → 全组成员入 members；同值多支不入。
  6. members 按 obs["index"] 升序返回。
- 副作用：无。
- 返回：list[obs]。
- 规则条目：
  - R-A2-29 矛盾池＝被引且在池 kind 内、同 subject（内容首段名）≥2 支且「：」后值不同——全组成员列明（列明含各支原文）。
  - R-A2-30 agg_row/lineage/notice 不入池（行级事实按 井@日 独立键、元信息无出处面）；同值多支不入池。
- 耦合：无外部符号（纯字典操作）。
- 疑点（只列不判，不静默）：
  - D-A2-31 subject 以全角「：」切分且按原文精确分组——同一对象名写法差异（空格/半角冒号）拆成不同组（漏判矛盾）。
  - D-A2-32 值比较取「：」后原文全字符串（含后续「：」文本）——格式差异（空格/换行）即算不同值（可能误判矛盾）。

### `_lineage_closing_note`（L1035-L1045）｜血缘卡⑤收口注记行提取
- 分支表（穷尽）：
  1. 逐观察找 locator.kind == "lineage"；非 lineage 跳过。
  2. 该观察 content 逐行：strip 后 startswith("⑤") → 返回该 stripped 行（首个命中）。
  3. 该观察无命中 → 继续扫下一 lineage 观察。

- 副作用：无。

- 规则条目：

- 疑点（只列不判，不静默）：
