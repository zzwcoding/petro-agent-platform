- 副作用：emit notice（type=budget_converged，恰 1 次）；step 无；notice 同时进返回的 notices 列；持久化写无（本函数不直接写 store——updates 由调用方返回后经图 checkpoint 落）。

  - R-B1-05 收敛答案走直答通道（draft_kind=direct＋next_intent=answer）——answer 节点免起草、免核验收口（同 `_direct_answer` 出口语义）。
  - R-B1-06 收敛不产生步记录（steps 无追加）——收敛事实面＝notice＋budget_hit，答案落 answer 步。
- 耦合：`appv2.runtime.budget.unfinished_notice`／`material_rows`／`NO_MATERIAL_SHELL`；`appv2.runtime.events.EventBus.emit`（经 deps.bus）；`appv2.runtime.state.INTENT_ANSWER`。
- 疑点：

### `_tool_note`（L1237-L1268）｜执行台账→过程档案条目（五形分型措辞）

- 消费：参数 tool_name、args、result（ToolResult dict 投影）；经本文件 `_payload_fingerprint`（L537）算 params。
- 装配：产出 process_notes 台账条目（`_note("tool", "{tool}：{status}", digest)`）——调用方追加；V2-79a 起承载面为 process_notes（不再入 messages 历史）；batch_node 另将「工具台账行」user 消息逐支入链（L3355-L3361，段外）供作答轮执行史面。
- 调用：callers＝`_apply_result`（L2067——decision legacy 执行回执路径）／batch_node（L3351——四相位逐支执行）；非 LLM、非工具调用（结果已产出，本函数只记账）。
- 分支表（穷尽）：
  1. status == STATUS_OK → digest＝`{tool} 参数：{params} → 结果：{N} 行`（N＝`len(result.get("observations") or [])`）。
  2. status == STATUS_ASK → digest＝`{tool} 参数：{params} → 结果：0 行（挂起：审批）`。
  3. 其余（failed 为主）→ `error = result.get("error") or {}`；`reason = str(error.get("message", "校验未过"))`；`category = str(error.get("category", ""))`：
     3a. category == CATEGORY_BAD_ARGS → `{tool} 参数：{params} → 校验拒（拒因：{reason}）`——参数校验未过、引擎未执行（非闸拒），修参重投。
     3b. category == CATEGORY_RETRYABLE → `{tool} 参数：{params} → 暂不可用（拒因：{reason}）`——可恢复（引擎侧同参重试一次）。
     3c. 其余（含 CATEGORY_REFUSED 与任何未知/空分类）→ `{tool} 参数：{params} → 闸拒（拒因：{reason}）`——不重试不改写。
  4. 恒返回 `_note("tool", f"{tool_name}：{status}", digest)`（phase="tool"、title="{tool}：{status}"）。
- 副作用：无（纯构造；process_notes 追加由调用方）。
- 返回：dict（process_notes 条目：phase／title／digest 三键）。
- 规则条目：
  - R-B1-26 五形分型措辞：ok＝N 行／ask＝0 行（挂起：审批）／bad_args＝校验拒／retryable＝暂不可用／refused＝闸拒——拒因逐形如实、负信息落档（同参重投由模型读档案摘要自主避免——V2-79c 渲染；V2-37 机器闸兜底）。
  - R-B1-27 参数面＝`_payload_fingerprint`（键序归一紧凑 JSON——与 V2-37 载荷指纹同规范）；行数＝观察条数。
  - R-B1-28 分型边界：bad_args/retryable 显式比对，其余一切归「闸拒」形——CATEGORY_REFUSED 未显式引用（值同为 "refused"）。
- 耦合：本文件 `_payload_fingerprint`（L537）与 `_note`（L1227）；`appv2.tools.STATUS_OK`／`STATUS_ASK`／`CATEGORY_BAD_ARGS`／`CATEGORY_RETRYABLE`。
- 疑点：
  - D-B1-17 else 分支收口宽：CATEGORY_REFUSED 与未知/空分类同措辞「闸拒」——分类值异常（空串、未来新值）显示为闸拒，分型失真无防线（ToolError 构造侧闭世界校验在 tools/schema.py，state 恢复段数据是否恒合规本段不复核）。
  - D-B1-18 reason 缺省「校验未过」对全部 failed 分支生效——retryable/refused 缺 message 时也显示「校验未过」措辞，与分型语义可能不符。
  - D-B1-19 status 无 STATUS_ALL 白名单校验——非三值异常数据落入 else（failed 形），title 会原样显示该异常值。
