   - 触发词 `VERBATIM_NEED`＝`逐字(?!段|落|可|查|比对|一致|在场)`｜`措辞(?!不|如|随|同步)`｜`替换为`｜`追加段`｜`行为定义`；

   - 触发而无载体 → FAIL。**注意**：验收节的「逐字可查／逐字比对／逐字落字」类判据被负向排除，**不算**施工指令。

**AGENTS.md 6b 在本类改动上的适用判据**（需／不需逐字稿）：

| 改动 | 是否需逐字稿 | 由头 |
|---|---|---|
| 前端加载态新增/改 UI 文案（如「加载中…」） | **需** | 属「措辞／合同文案」——不给逐字即逼子代理自行设计文案 |

| spec 新增/改行为定义（L1 加加载态、新增验收表行） | **需** | 属「行为定义」；且行内须带 `〔来源：…〕` 防第 2 条 |

| 测试新增/改判（用例名＋断言） | **不需** | 非施工指令；用例名可写进验收节 |
| 验收节「逐字可查／逐字比对」 | **不需** | 正则负向排除（`:45`） |

**实操坑**：任务段里写「逐字稿」三个字本身就会触发第 5 条；载体必须**也在任务段内**（写进 `## 施工基准` 即可，`先读` 之后不算）。
