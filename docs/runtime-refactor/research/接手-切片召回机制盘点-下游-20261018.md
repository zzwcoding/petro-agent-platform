## 2. 截断层级对照表（供给窗 vs 渲染层）

| 项 | L1 供给窗（上游，per 子问题调用） | L3 渲染窗（下游，per 作答调用） |
|---|---|---|
| 预算/帽 | `M = min(24, 6×子问题数)`（`schema.py:119-135`） | `DEFAULT_MAX_OBSERVATIONS = 24`（`materials.py:62`） |
| 帽是否同源 | **两个独立 24**：`SEND_BUDGET_CAP` 与 `DEFAULT_MAX_OBSERVATIONS` 各自「单点」，**无共享常量、无相等约束** | 同上 |
| 作用面 | 全族（family 配额：hints 族共享 3/4，其余 1/4） | **只作用检索族 report**；权威/台账族无帽 |
