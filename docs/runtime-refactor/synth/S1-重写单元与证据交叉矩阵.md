## 五、缺口与待裁决（本表暴露的问题）

1. `【缺口-1】` **arch 票面 → recon 规则 的接线缺失**：本表给到「票在哪个单元」，但「票的哪条规则对应现状哪条 R 规则」没有机械锚（arch↔recon 零互引，见前期普查）。逐模块提案需要这层接线，建议下一步做「A-票规则 ↔ R-现状规则」对位表。
2. `【缺口-2】` **对接面 T 规则 → 内部 R 规则的接线缺失**：同因（iface↔recon 零互引）。
