## 六、对「材料是否合格」的判定

- **代码腿：合格**（齐、锚 commit）。
- **测试腿：资产合格、登记不合格**——测试网有 52 个 v2 文件/19333 行且直连 runtime 各模块，但 recon 未把规则接到测试上（7/22 片有显式引用）。→ **补登记即合格**，不必新建测试网。
- **票面腿：片级合格、规则级不合格**——21/22 片有票号，缺 L1a；规则级仅 37/730。→ 需补一层「票↔规则」对位。
- **总判**：材料**够开工**（不是缺料，是缺**索引**），但 00 §4 的机检判据（每条规则三腿齐）**未达**——达标的路径是本表 §三/§四 两张表 + 逐模块提案时逐条过，非回炉重做取证。
