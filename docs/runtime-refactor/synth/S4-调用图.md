## 二、节点跳转图

### 2.1 生产态（four_phase=True，四相位——ADR-0004/0005）

```
START → understand ──┐
                    ↓
              ┌→ clarify（相位①业务澄清）⇄ clarify（拒因回喂自环／ask 挂起恢复）
              │      │ discover ↘            ↗（发现探查）
              │      ↓             discover ⇄ observe → (decision→clarify)
              │   toolmatch（相位②工具匹配）⇄ toolmatch（拒因回喂自环）
              │      ↓
              │   precondition（相位③前置条件机）⇄ precondition（审批恢复边）
              │      ↓
              │   batch（相位④批量执行）
              │      │ decision → clarify（引擎 ask 挂起／失败子集回炉①）
              │      ↓
              └─ answer（起草）→ verify（核验，就地改写）→ answer（收口）→ END
```

- **相位①→②→③→④ 主干线性**；四相位节点只在 `four_phase=True` 时挂（`build_graph` L4070-4105）。
- **「回决策」边全部重定向 clarify**：所有 legacy 表里 `INTENT_DECISION` 值改写为 `NODE_CLARIFY`（L4074-4076）——即「回第一决策相位」。
- **发现探查环**：clarify/discover/observe 之间的 discover 小循环（≤10 次全 run）。
- **answer⇄verify 环**：answer 起草（`INTENT_VERIFY`）→ verify 核验（就地改写，`INTENT_ANSWER`）→ answer 收口（`_finalize` → END）。

### 2.2 legacy 态（four_phase=False，七节点——骨架期形态）

```
START → understand → decision ⇄ {discover ⇄ observe / execute ⇄ observe} → answer ⇄ verify → END
```

- 七节点：`understand / decision / discover / execute / observe / verify / answer`（`_ROUTES` L3993-4032）。
- `decision` 为 legacy 决策出口（D-C-12：**生产态不可达**——四相位下其入边被重定向 clarify）。
- 保留于代码：`_ROUTES` 为两态共用真源（L4068 浅拷贝后改写）。

### 2.3 路由判据与方法

- **条件边唯一判据**＝`_route(state)`＝返回 `state.next_intent`；空值缺省 `answer`（H L4035-4036）。
- **白名单路由**：每节点只接受 `_ROUTES[node]` 表内 intent 键，表外键在 langgraph mapping 缺键时报错（`_route` 零兜底，D-H-20）。
- **START 定边**：`START → understand`（L4106，唯一固定边）。

## 五、本图暴露的结构问题（重写输入）

- `【结构-1】` **legacy decision 节点**（D-C-12）：生产不可达，与 clarify 能力重叠——重写**整体废弃**，决策语义并入 M2。
- `【结构-2】` **`_route` 零兜底**（D-H-20）：闭世界外非空 intent 原样返回，缺键在 langgraph 侧炸——重写须定 intent 值域校验点。
- `【结构-3】` **answer 自环**（D-H-19）：answer→answer 自环存在，非收敛路径会再入——重写须查是否可达。
- `【结构-4】` **verify/answer 表无 decision 键**（D-H-18）：这两节点若发射 decision 值即缺键。
- `【结构-5】` **checkpointer 缺省 None**（D-H-22）：无持久化图，挂起/恢复依赖调用方注入——重写须守 ADR-0002 红线（挂起/恢复硬需求）。
- `【结构-6】` **四相位重定向为「值改写」**（D-H-21）：语义＝回第一决策相位，重写须把「回决策」新语义显式化（别再靠字符串值同一）。
