# 设计总纲（Owner 2026-10-15 定盘）

## 一、目标

要设计的是一个 **受控的 ReAct 多轮对话 agent**：

- **ReAct**：模型自主循环（推理 ↔ 行动）——不是写死的线性流水线；「这句话什么意思、该不该、下一步做什么」由模型定。
- **受控**：程序在关键处**约束**——结构、硬不变量、执行权限；保证**模型出错也不出大事故**。
- **多轮对话**：历史进上下文；追问承接前轮。

## 二、总纪律（铁律）

> **凡语义判断，一律交模型；程序只做两件事——**
> **① 按模型给的结论「机械分派」；**
> **② 守「结构约束」。**
> **绝不拿规则/词表去替代模型的语义判断。**

（与 ADR-0005「LLM 出语义，代码出判定」同源。）

## 三、推论（拿它当尺子，量每一处设计）

1. **安全/只读等硬约束，落「执行层 / 数据层」**（系统**没有**那样的工具、**拿不到**那样的数据）——**不靠词表拦问题**。
2. **词表 / 关键词匹配只作「辅助快路径」**（明显情况的友好早退），**不作判据、不作唯一防线**。
3. **程序的活**：输出契约、解析、分派、状态推进、留痕。**模型的活**：「这句话是什么意思 / 该不该 / 走哪条」。
4. **模型出错靠「结构」兜底**（核验、无据不进答案、工具权限），**不靠加规则去补**。
5. 判据一句：**凡写得进「如果句子里出现 X 词就 Y」，就要警觉——那多半是程序在替模型做语义判断。**
