## 一、现状（这一段现在从头到尾怎么做）

**1. 四个入口**（appv2 全部 HTTP 端点，前缀 `/api/v2/chat`）
| 端点 | 方法/路径 | 干什么 |
| --- | --- | --- |
| E1 | `GET /runs` | 任务列表（最近 N 条，7 键摘要） |
| E2 | `POST /asks` | 三形态合体：①仅 question＝提问 ②`resume_run_id`＝断线重连 ③`question+followup_run_id`＝追问 |
| E3 | `POST /runs/{id}/resume` | 挂起续推（用户答了反问/审批） |
| E4 | `GET /runs/{id}` | run 详情（状态＋步骤＋挂起帧） |

**2. 身份**：头 `X-Dev-User`；**缺头/空白＝落默认角色、不报 401**；非五个角色键才 401（`security_unauthenticated`）。开发期身份桩，正式 OAuth 只动 `resolve_actor` 一处。

**3. 开流前检查**（全部在流打开之前同步返回）：问题去空白为空 → 400；`Last-Event-ID` 非整数 → 400；只有 `Last-Event-ID` 没有 `resume_run_id` → 400；`resume_run_id` 与 `followup_run_id` 同在场 → 409；任务号不存在 → 404；任务没在等待态却要续跑 → 409；没带身份 → 401。

**4. 建任务、起计时**：受理即建 run 行、写 `running`；播种预算与时限（`budget`／`started_monotonic`／`deadline_monotonic`）；派后台任务驱动图。

**5. 开流与收流**：
- 三端点流**首帧恒发 session**：`{run_id, resume:bool}`；
- 帧号＝**响应内自增计数器**（非全局、非 runtime seq）；
- 断线重连：`Last-Event-ID` 作游标，从缓冲重放（不重跑）；可尾随在跑的 run；
- 流尾恒发保留帧：正常→`done {run_id}`；异常→`error {code:"chat_stream_failed", message}`；
- 挂起铁律：`ask` 帧之后**照发 done**（挂起看 ask 帧，不看 done）；
- 失败腿：引擎/网关异常→`notice{type:"run_failed"}`＋正常 done（**不触发 error 帧**）。

**6. 错误形**：恒 `{code, message[, detail]}`；7 个错误码（见上表）；**开流后一律出帧、不回 HTTP 状态**。

**7. 缓冲与并发**：`RunStreamRegistry` 进程内单例，**无淘汰/无上限/无 TTL**；执行器侧全局并发闸（ADR-0003）。

## 三、最佳实践对照（`research/最佳实践-节点-进门.md`，本地材料）

- **开流前只做「能同步判定」的检查**（认证→鉴权→预算）；**开流后错误改用流内错误帧＋单调游标**，不再回 HTTP 状态。（HandBook ch6/ch9/ch12）
- **通信契约六要素当开流检查表**：含「背压」声明——本项目缺背压。（HandBook ch12）
- **单调游标＋服务端去重**；任务唯一键/去重键（只读场景退化为「不重复建任务」）。（HandBook ch10）
- **入口三步＋清除/覆盖客户端伪造的内部身份头＋审计记「准入」与「结果」**。（HandBook ch9）
- 要警惕：**多层重试乘积放大**、**把「流结束」当「任务结束」**、挂起超时自动替用户选默认项。

## 五、我的建议 ＋ 重写规划（草案）

**重写后的「进门」是什么样：**
1. **入口三步（顺序固定）**：认证（认身份）→ 鉴权（能不能做这件事）→ 预算/并发闸（还让不让进）；三者都能同步判定，**在开流前**。
2. **清除/覆盖客户端伪造的内部身份头**（正式接 OAuth 前就把这个口收掉）。
3. **开流前检查清单固定**：问题空/参数形/身份/任务号/状态 → 4xx；清单**进机器闸**（合同覆盖率把 appv2 也纳进来）。
4. **游标改单调**：全流一个单调源（帧号跨段不重启、重放不位移），断线重连只要报「最后收到的序号」即精确续上。
5. **错误收口**：对外只出稳定 code/message，原始异常只进内部留痕。
6. **缓冲加容量闸**（上限/TTL/观测），并把「任务结束」与「流结束」分清。
7. 保留不变：4 端点形、错误包形、session 首帧、`done`/`error` 收场、挂起铁律（ask 后照发 done）。
