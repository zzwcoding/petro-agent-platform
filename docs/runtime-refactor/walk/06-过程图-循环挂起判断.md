## 二、挂起节点（停下来等用户）

| 挂起点 | 为什么停 | 现状恢复语义 |
| --- | --- | --- |
| 澄清反问（T3d） | 问题/口径有歧义 | 发反问卡（问题+选项），**等待不计轮**；用户选完**从停下处接着跑**、重进澄清相位 |
| 外部表审批（T5b） | 查询用到平台外的表 | 挂起等用户批/驳；批→表进白名单＋按原计划继续（**计划不重排**）＋回前置再判；驳→该子问题如实拒答（不重试） |
| 引擎缺参反问（T6a） | 查询工具缺参数（如「最近」解析不出） | 停下等用户答；答完**回澄清相位**继续跑 |

**共用语义（现状）**：挂起＝`interrupt`；恢复＝`Command(resume)`；**等待不计轮/不计时**；`resume` 会**重置轮预算**（每用户输入周期 3 轮）。

## 三、循环 / 回边（会转圈）

| 循环 | 现状上限/边界 | 依据 |
| --- | --- | --- |
| 发现小循环（澄清⇄发现⇄观察） | 每轮 ≤2 次、**全 run ≤10 次**；首次「到预算还想查」不算轮，第 2 次起占轮 | ADR-0005；`R-C`/`E1` |
| 大循环（回炉重做） | **每用户输入周期 3 轮**；resume 重置轮预算合法；成功子问题**保留不重跑** | ADR-0005 轮语义 |
| 拒因回馈自环（决策解析拒） | 轮照耗（不豁免）；拒因入 `decision_error` 回喂 | `R-C-25` |
| 失败子集回炉（批量→澄清） | **只带失败的**（附拒因）；成功结果保留绝不重跑 | `R-G`/T6b |
| 换链回炉（T5e） | **一次为界**；再触发同支＝如实拒答终局（不环） | `R-F`/V2-43 |
| 核验改写环（作答⇄核验） | verify 就地改写 → 回 answer 收口（非无界） | `R-H`/T8a |
| 同参重投闸（V2-37） | 同参二次发射→**确定性拦截**＋虚拟拒因回喂＋自环（轮照耗） | V2-37 |
| 连续澄清上限 | 连续 ask **≥6** → 截断＋带材料如实直答（不环） | `CLARIFY_ASK_CAP=6`（S3 C-04） |

**共用语义（现状）**：轮预算按「每用户输入周期 3 轮」计；ASK 挂起不计轮；到限**不卡死**（先交付已取得材料＋notice 列明未完成）。

## 四、按总纪律归责后，暴露的问题

1. **前置条件机里混着语义判断**：8 个判定位里，「禁用词」「合法口径」是**语义**（该交模型）；「外表越集/在册绑定/新鲜度窗/单井支持」是**结构**（程序）。现在**一律程序判**——违反总纪律。**（已治：§06 Q-C／§12 把语义类上移到匹配相位；业务树 §02/§03 的「待重估」亦已由 §07 重裁。）**
2. **循环上限散落各处**：发现 10／大循环 3 轮／回炉一次／连续澄清 6／同参闸——**没有一处统一声明**，重写须收成一处（预算表）。
3. **挂起恢复语义要写死**：从哪接、重算什么、哪些不重跑——现在靠散落注释，重写须成文。
4. **「判断以什么为准」没有统一口径**：同是判断节点，有的模型判、有的程序判、有的混——须按总纪律逐点钉死。
