| 1 | 澄清/分解 | **程序对象歧义 ask 门（新增，澄清 LLM 之前）**＋反问/拆子问题 | 程序门＋LLM |

**新链形（H 批 system 承载位保留，V2-82 改数据区）**：
```
链本体（持久化）＝ [system 背景块] [user 题面+环境数据区(已瘦身)] [a 读题应答] [user 澄清动态段] [a] … [user 作答动态段(材料+白话注记)] [a]
每调用请求面     ＝ [system 本环节规章] + 链本体
```
- **环境数据区瘦身（V2-82）**：删与背景块重复的"本系统"介绍句（2004→1057 字）；指标/术语从"逐条注解形"改"顿号串名字形"——重复注入消除（Owner 裁决：任何信息只在被需要的最早环节注入一次）。
- **程序预识别行（V2-82a，新）**：环境区尾部一行推荐——
  ```
   - 程序预识别（仅供参考——可能不准，以你的判断为准）：主体候选：渤中34-5油田；术语候选：检泵周期
  ```
  程序侧 `tools/subject_terms.py`（复用 anchors/well_ids/glossary 现成件，纯程序零模型）；理解输出 JSON 新增 `subjects`/`terms` 结构化字段（additive 宽松解析，不拒单）；模型与程序不一致记 process_notes。
- **程序对象 ask 门（V2-82b＋82f，新，节点 1 入口）**：题面无主体（模型槽空→回退程序候选，题面抽得到＝对象已定不问）∧ 指标粒度要求主体 ∧ 油田实例≥2 ∧ 预算内 → **澄清 LLM 之前零模型弹 ask**：
  ```
  这道题问的是「检泵周期」——系统里有多个油田的数据。请确认要查哪一个：
  [渤中油田, 渤南油田, 渤西油田, 都要（分源对比）]
  ```
  选项→state.subjects；「都要」= 哨兵 `__all_fields__`（消费面未做，见 §四）。
- **白话注记（V2-82e，A 方案收官）**：引擎注记生成单点直接产用户语——
  ```
  共检索到 52 条材料，23 条用进了答案；另有 29 条已找到但未用进答案（受送入答案的数量限制）；以下材料来源说法不一，各保留了代表条目：《…》；以下来源因数量限制未纳入：《…》
  ```
  计数同时落结构化 payload（RetrievalBundle.recalled/sent）；四条常量＋扩席段全入裸行话闸看管，产文零「支/召回/送窗/口径」。

## 二、逐节点解剖（条件 → 加入什么 → 真实实例）

> 角色标注：【S】=调用级 system（规章）／【S-链】=链首 system（背景）／【U】=user／【A】=assistant。实例均逐字。

### 节点 0 · 读题
- 条件：每问必进一次。加入：【S】读题规章；【U】题面＋任务书动态段（瘦身后环境区＋预识别行）。
- LLM 输出 JSON 现形：`{"route":"full","text":"理解：…","metric_candidates":["检泵周期"],"subjects":["渤中34-5油田"],"terms":["检泵周期"]}`——后两键可空、类型不合被忽略不拒（宽松 additive）。

### 节点 1 · 澄清/分解
- **程序门先行**（上链形节）；门不命中才进 LLM 澄清。
- 【S】相位①规章；【U】动态条＋拒因回喂＋问题组；台账常驻5000字＋§A指南＋样例留【U】链（run级一次注入）。
- **A13 修（混合组路由）**：前置条件机之后，`allow` 排除本轮新触发支 → 可执行支非空⇒进批量（部分结果先行）；唯纯触发组⇒回炉①澄清；无 allow⇒作答。修前 bug：任一触发标记即整组回炉烧轮（V1/recon 合同语义恢复）。

### 节点 3 · 前置检查（纯程序）
- 窗闸/绑定闸/词面门/互斥闸/换链终局。实例【U】反问卡：「这个问题没说清要看哪段时间——请先选一个时间范围……」

### 节点 4 · 执行
- 观察材料装配规则：权威族全量／检索族24帽／同报告≤半数＋多样性配额；血缘→一行口径行。
- **术语锚扩展（V2-82c）**：题面命中术语/别名→"规范名＋全部别名"注入关键词腿查询文本（`term_anchor_tokens`）——「问别名、切片存正名」端到端召回成立。
- **主体保底席（V2-82d）**：锚命中面从"只看切片正文"扩为 **正文∪报告名∪well 字段**——题面点名油田/井号，该来源切片保底进窗（B-正6 形黑盒验证）。
- **白话注记**：见 §一实例（最末【U】，模型如实转述）。

### 节点 5 · 作答
- 【S】作答规章（【答案要求】十条＋白话表）；【U】题面件＋子问题清单＋观察材料＋白话注记（最末尾）。

### 节点 6 · 核验（纯程序）
- 有无据／数值对账（井号日期不算数值断言）／删句／油田归属对账／坏引标剥除／残尾护栏。

### 节点 7 · 交付
- 正文＋supplement（lineage/citations/split/attribution）＋notice＋citation 帧。
