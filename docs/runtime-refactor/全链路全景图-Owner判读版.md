## 一、七个节点与 H 批后的新链形

| # | 节点 | 干什么 | 谁干活 |
|---|---|---|---|

**新链形（H 批，已真机验证 48/48 调用）**：
```
链本体（持久化）＝ [system 背景块] [user 题面] [a 读题应答] [user 澄清动态段] [a] … [user 作答动态段(材料+注记)] [a]
每调用请求面     ＝ [system 本环节规章] + 链本体        ← 规章不入链、用完即散
```
- 背景块（「【系统背景】你是"问一问"…作用/原理/机制/目的」，206 字）链首恰一次。
- 环节规章（读题合同/相位①②合同/答案要求十条＋白话表）走调用级 system——**选这个形态的原因**：供应商走 Anthropic/litellm，会把链内所有 system 合并成一个，骑链方案会让每个环节看见全部规章（串味）。开票与技术核实见 `proposals/H批-开票-system承载位.md`。

## 二、逐节点解剖（条件 → 加入什么 → 真实实例）

> 角色标注：【S】=调用级 system（规章）／【S-链】=链首 system（背景）／【U】=user／【A】=assistant。实例均逐字。

### 节点 0 · 读题
- 条件：每问必进一次。加入：【S】读题规章（【场景】＋【输出契约】，约1500字＋静态环境装配2100字）；【U】题面＋任务书动态段。
- 实例【S】：
```
【你的输出与它的消费方式】输出固定两行，格式强制：
第一行「理解：〈一句话〉」……第二行「指标候选：〈逗号分隔〉」——……指标名必须逐字出自本行
```
- LLM 输出：JSON（理解＋指标候选）。

### 节点 1 · 澄清/分解
- 条件：读题通过后每轮。【S】相位①规章（合同2400字＋动作契约）；【U】动态条＋拒因回喂＋问题组；台账常驻5000字＋§A指南＋样例**留【U】链**（run级一次注入，模型从链首可见——刻意设计）。
- 实例【S】（动作契约逐字）：
```
- 分解：{"action": "decompose", "question_group": {"subtasks": [{"id": "s1",
  "question": "子问题原文", "ledger_notes": "〈精确指标 slot 名〉〈绑定态〉〈锚定窗〉",
  "chain": "data"|"knowledge", …}]}} ——ledger_notes 必带——从下方台账全量块逐字转抄，不改写不杜撰。
```
- 真机行（D-诱9 修复后已能四数交付；修前锁死形）：`"检泵周期｜未绑定｜2026-08-01~2026-08-31","chain":"data"`
- 程序闸门：`core.py:463` 禁探查（问题组在场即拒）＋换链一次为界——**D 方案（解封）未做**。

### 节点 2 · 工具匹配
- 【S】相位②规章1560字；【U】问题组清单＋锚注入＋动态条。

### 节点 3 · 前置检查（纯程序）
- 窗闸/绑定闸/词面门/互斥闸/换链终局。实例【U】反问卡（用户可见）：「这个问题没说清要看哪段时间——请先选一个时间范围（含糊的说法我不会自己猜，也不会默认取最近一段时间）」

### 节点 4 · 执行
- 观察材料装配规则：权威族全量／检索族24帽／同报告≤半数＋多样性配额；血缘→一行口径行。
- 实例【U】口径行：`[2]（authoritative｜agg.fct_daily_metering）【口径】日产油量（单位：吨）…｜来源：agg.fct_daily_metering（agg 星型读模型 ⋈ 井维度 ⋈ 日期维度）`
- **引擎注记**（生成单点 `retrieval/domain.py:427`，追加在节点5提示词**最末尾**【U】）：
```
引擎注记（…如实转述，不得静默丢弃）：召回 46 支/送窗 11 支；已召回未送窗 35 支；缺位来源（预算未及）：《…》
```
← **这是白话化三层失效的总根源（A 方案未做）**。

### 节点 5 · 作答
- 【S】作答规章（动词钉死＋【答案要求】十条全文＋白话表300字＋汇总合同＋起草合同）；【U】题面件＋子问题清单＋观察材料＋引擎注记（最末尾）。
- 实例【S】白话表：「【术语白话表】口径＝这个数是按什么规则算的；台账＝平台里登记指标和术语的名册；水位＝数据目前更新到哪一天；…」
- LLM 输出：答案 Markdown。

### 节点 6 · 核验（纯程序）
- 有无据／数值对账／删句（判据已收窄：井号日期不算数值断言）／油田归属对账／坏引标剥除／残尾护栏。实例：NQ-M4 整行全属另一油田→拒收；「W-22井教训…」修前被删、修后保留。

### 节点 7 · 交付
- 正文＋supplement（lineage/citations/split/attribution）＋notice＋citation 帧。
