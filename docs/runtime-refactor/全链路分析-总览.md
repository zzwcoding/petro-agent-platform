- 关键前提：帧=text 帧是**起草稿**（核验前发出），删句效果只见于真机交付——这解释了"批内残尾 0、手工复跑中招"

## 一句话结论

**大部分"模型答得不好"其实是输入侧定形：模型最省力的策略是转述它最后读到的原文（引擎注记尾段、材料切片），而输出侧的合同/词表/示例三层都被这一次"原文转述"击穿。措辞类病灶只能程序接管（改渲染单点），正确性类病灶要前移到"谁进窗＋交付装配"。**
