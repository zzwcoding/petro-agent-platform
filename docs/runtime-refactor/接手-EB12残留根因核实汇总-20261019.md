## R1 相对窗锚定不统一——**根因在程序，不在模型**

| 判定 | 证据 |
|---|---|
| **主因①：同一条 prompt 内程序自注入两条互斥锚定指令** | `prompts/task_book.py:171`「数据水位：2026-08-31——题干中「本月／去年」等时间词以该日为锚」 **vs** `ontology/petro/skill-guides/instructions.md:27-33`「窗词锚定（执行日 2026-10-08）…去年→2025-01-01/2026-01-01」 |
| **主因②：生效路无「词面↔窗」一致性闸** | `appv2/query/domain.py:229 parse_time_window` 在 **appv2 零生产调用**（仅 v1 用）；`tools/handlers.py:895-916 _plan_from_draft` 直取模型载荷；`query/domain.py:561-578 check_plan_window_bounds` 只封未来/窗长（水位滚动年与自然年**双双合法**） |
| 模型层＝近因，非根因 | 同 prompt 同词面**抽签**：`数-排1`（run-34f05899）锚水位滚动年 2025-09~2026-08；`数-排3`（run-cdd63d1d）理解步也写「以数据水位 2026-08-31 为锚」但 decision 改判 2025 自然年 |
| 程序时钟**未错位** | 实跑冻结日＝2026-10-08（`数-闸2` 兜底窗 2026-10-06~2026-10-08 反证）；`parse_time_window` 两题都算对（去年→自然年；本月→2026-10-01~10-08→会被新鲜度闸拦停） |

**修法**：①机制——`_plan_from_draft`／`validate` 加「问句命中显式时间词时，模型窗必须＝`parse_time_window(question, today)`」闸，不等即拒→回炉（v1 在 `ground_pinned_window` 的 `status!="missing"` 支补同款）；②提示词——改 `task_book.py:171` 为「水位只用于新鲜度拦停/改绑，相对时间词一律锚执行日」（v1 `runtime/orientation.py:260` 同步）。

## R2 Q16 澄清循环——**两层根因，判分只看到一层**

- **层 1｜重抛闸缺位**：三处 ask 唯一收口＝`orchestration/graph.py::_suspend`（:278-287），但指纹/降级只长在 `clarification/core.py::_on_ask`（:796-799,825）。前置条件相位（`graph.py:602-605 → _precondition_frame:290-317 → _suspend`）**不查** `asked_fingerprints`／`answer_slots`；其步记录（`preconditions/core.py:463-476`）不带 `PAYLOAD_ASK_FRAME` ⇒ 连 `ask_cap=6` 也不拦（Q16 实测重抛 3 次，发射者＝前置条件机：seq 8/15/20 `hit_rule=ask`）。
- **层 2｜消费面缺位**：答复只落 `answer_slots["caliber"]`，**从未译成 `plan.caliber_key`**；位 4 判据（`tools/precondition.py:490,534-552`）只读 `plan.caliber_key`，唯一产它的是**工具匹配相位**（`tool_matching/matching.py:374`），该相位增量条（`decision_round.py:642-648`）零 `answer_slots` 行，合同还明文「口径支歧义不归本相位」（`prompts/constants.py:161`）⇒ 回答无处落地，静默取默认。
- **EB11 与 EB12 同根两表象**：EB11 硬塞 `ledger_notes` 被对账拒；EB12 对账改判「未绑定」放行后静默丢。**只加指纹会退化成「不再重抛但 caliber 仍未绑定」**。

**修法**：①`_suspend` 落统一闸（指纹＋降级＋计步，槽位取 `detail.slot`，覆盖两相位）；②`preconditions/core.py::gate_all` 把 `answer_slots`／`degraded_slots` 的 caliber 作**位 4 确定性输入**传 `tools/precondition.py::judge`，命中即 allow＋note。

## R3 Q05/Q39/Q18 选项——**全部是模型生成，生产零闸**

- 三题 ask 帧 `detail.slot="clarify"`＋`emission.action=ask` ⇒ **模型生成**（程序 `subject_ask` 落的是 `ASK_FRAME_DETAIL_NONE`）；Q39 的「本月」原问句无此词＝模型自造月锚。
- V2-110 判据是**离线提示词条件化替身测试**，只咬 options 内：①纯井号形 ②「近N天」 ③「X油田」区块粒度；**生产零闸**（`transport/frames.py:58-74 _check_ask` 只校验恰四键＋kind）。Q05 井号在 **prompt 正文**（不咬）、Q39「本月」非「近N天」（不咬）、Q18「近30天」能匹配但无生产闸。V2-118 的 Q16 离线复现恒走 `clarify()` 脚本腿，**从未走前置条件相位**。

**修法**：`_suspend` 同点落「选项可消费性」程序闸（零可消费取值即拒/降级；井号形扫描扩到 prompt 正文；窗锚词扩到 本月/当月/上月 ∩ 注入 watermark 越界）。

## R4 收口空答——**三例并非同因**

**①`B-正7`＋②`数-反1`＝同因族**：模型原话是**整篇 0 换行的单行 JSON**（①479 字 `{"action":"finalize","answer":{…}}`，`answer` 是 **dict**；②3713 字 `{"matches":[…]}`＝工具匹配相位发射形）。`extract_finalize_answer`（`emission.py:92-117`，条件③ `:115` 只认 `isinstance(answer,str)`）**均判负→零提取**；`strip_emission_fences` 规则 3（`emission.py:154-159` 裸 JSON 行）**整行剥除**——规则本是行级，而应答 0 换行 ⇒「一行」＝「整篇」。
「不推空答案」兜底**只做到了不编造**：`core.py:671-674` 零 text 帧＋`gaps` 落 `missing`，而 `gaps` 是**审计面不上屏**（`answering/constants.py:128-137`）⇒ 用户可见面仍空。

**③`数-察2`＝异因**：澄清三段槽位对账**四连拒**→轮预算 4/3→零材料收敛占位串（`closing.py:95-106`）。真缺陷＝**判据与教具不自洽**：段一判据用投影 `slot` 列（`clarification/core.py:619`），注入块行首名却用 `value` 串「日产油量（吨）：…」（`decision_round.py:221-224`），而【期望形】写「台账行首名」（`clarification/constants.py:238-240`）⇒ 模型照抄必被拒。**审批帧不是消失而是从未产生**（该 run 未进前置条件机）；与 V2-118 无因果。

**修法**：①`emission.py:100-117` 条件③放宽为「串**或** mapping 取其 `text`」；②整枚 `matches` 形复用 `core.py:570-591` explore 回喂重读一次；③空稿路径产**用户可见**如实短句（非仅 `gaps`）；④`数-察2`：槽位判据与注入块教具同源（`slot` 列 vs `value` 串二选一）。

## R5 A 批「席位退化」——**3 题席位＋2 题非席位；仅 1 题确证 V2-100**

先确证 V2-100 在场：A 批 `quota_dropped` **EB11 0/69（键不存在）→ EB12 69/69**；`anchor_seated>0` **0%→61%**。

| `C-正3` | C2 席位（融合序变化，丢对策句支） | 否 | 推定 |

| `D-诱11` | **C2 席位，V2-100 确证**：`window_note` 逐字「以下条目因直接命中提问关键词获得保留：**《A-W11井完井工程报告》**」＋`anchor_seated=1`＋`quota_dropped=5`；目标报告席 5→2；两批 `recalled` 同 59、`budget` 同 6 | **是** | **确证** |

**根因（D-诱11）**：题眼锚保底席的命中面＝text∪report∪well 任一命中即给席（`domain.py:666-672`），A-W11 报告正文里一句「渤中 34-5 油田」就吃到席；且 `anchor_seat_tokens` 只收资产编号形 token（`domain.py:622-639`），报告期/族 token（如 `202608`）不参与。

**修法**：①锚保底加「报告级命中面」约束（禁凭正文单句吃席）；②`anchor_seat_tokens` 纳入报告期/族 token；③窗预算与子问题数解耦或给合并题 ≥12 下限；④`retrieval_calllog` 补落 `recalled_ids`。
