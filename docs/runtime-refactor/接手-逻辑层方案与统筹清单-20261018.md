**根因（逻辑层，不是代码 bug）**：
1. L1 取席顺序＝「族配额先填满 → 锚保底追加」⇒ 预算恒被配额吃干，锚保底永远排不到；L3 只能对 L1 留下的再选席，救不回来。
2. 节内展开只作用于「已召回到的那份报告」⇒ 对「召回错源/漏源」的 23 题无效。
3. `explore` 是**许可**不是**步骤**：模型拿不到「某子问题零支撑」的信号，主指令又是「写答案」，于是 0 次使用。

## 二、臆造（幻觉）上下文归因结论
