# 问一问检索问答链 · 人工评测操作手册（拟造报告 ×30 题）

> 目的：检验问一问（检索问答链＋FAQ＋图谱）在**长报告、强干扰、正反混合**提问下的可用性与准确性。
> 全部报告为拟造数据（结合本体台账术语/指标命名＋行业公开资料校准数值量级），答案已由编制方先行核定，你人工录入后逐题对照判分。

## 一、材料清单

```
eval/
├── README.md                    ← 本手册
├── reports/
│   ├── A-W11井完井工程报告.txt                      （6.0k 字·完井/射孔/防砂）
│   ├── B-渤中34-5油田躺井治理与检泵作业月报-202608.txt（4.7k 字·躺井/检泵/时率）
│   └── C-渤中34-5油田三季度注水调整与生产运行分析.txt （4.5k 字·注采比/欠注/双口径完成率）
└── answers/
    ├── A-题目与答案.md（8 正＋3 反）
    ├── B-题目与答案.md（7 正＋3 反）
    └── C-题目与答案.md（6 正＋1 澄清＋2 反＋1 观察题）
```

干扰设计说明（考题为什么"难"）：近名井号（W-11/W-111/W-12）、近值数字（512/521/215 天；101.9%/103.5%；386/402/291）、同章双口径（有效产量两支）、表外注释（W-32 检泵周期口径）、跨章答案（设计值 vs 实际值分居两章）、台账与报告两源（自然递减率）。

## 二、测试前准备

1. **环境**：后端 ：8000、前端 :5173、docker 六件（PG/Redis/MinIO/Neo4j）在跑；LLM 凭证在 `.env`（检索问答会真实计费，全程预计 ¥0.5～1 元量级）。
2. **D2 配置快照**：设置中心 → 搜索与回答，记录当前值（默认：faq_direct_hit 开、refuse_threshold 0.4、兜底 fixed、精排 fast、topK 20/20）。评测期间**不要改配置**；如改过，测完恢复并重测受影响题目。
3. **建议逐篇测试顺序**：A 库阶段 → A+B → A+B+C。原因：反题（如 B-反3 跨报告题）只在"单篇在库"时成立；三篇全录后全库检索会命中其他篇，那是合同口径（全库检索）的特性，不是错误。

## 三、建库与录入

1. B1 报告库 → 新建库「评测·渤中34-5拟造报告库」（模板默认即可——默认配置图谱抽取开启，C-正3 之外如想测图谱链可加问）。
2. 报告库页签 → 上传 → 选 `reports/` 下 `.txt` 文件 → 路由建议弹窗选择新建的评测库 → confirm → 五步轮询 done（parse/chunk/embed/index/enrich）。
3. 每篇入库真实费用预期：摘要卡＋问题卡约 3 次 LLM 调用＋图谱抽取按 chunk 数（合计单篇几毛钱以内）。五步 failed 时先看停止步与原因话术。
4. **注意**：评测库与既有演示库（冒烟·完井报告库，含 N-02 报告与 FAQ 种子）同平台共存。检索是全库面——FAQ 种子（如"N-02 井什么时候投产"）可能对部分问法直接命中 FAQ 链。若某题意外走了 FAQ/图谱链，如实记录链路再判断是否复测（换问法重问一次）。

## 四、逐题测试操作

1. A1 问一问 → 按答案册"题干"原句输入（**不要随意改写**——部分题考的是特定措辞下的行为）。
2. 每题观察四样：**思考树**（哪条链、S 级步进、skipped 情况）、**答案**（对照答案册）、**citation**（角标点击→出处抽屉→是否指向报告对应位置；点击回跳 B2 应定位到真实片段）、**澄清/兜底**（该弹澄清的是否弹、该拒不拒）。
3. 判分三档：✅／⚠️／❌（各答案册首行有口径）。反题判分口诀：**"给数就是错，说没有才算过"**（兜底话术或"报告未提及"皆✅）。
4. 每题记一行：`题号 | 链路 | 答案要点对错 | citation 对错 | 澄清/拒答行为 | ✅⚠️❌ | 备注`。

## 六、重点观察清单（本次评测最值钱的六个问题）

1. **fail-closed 引用**：所有 citation 的 fragment_id 点击回跳后，B2 高亮的片段是否真是答案出处（A-正7 的油嘴表、B-正4 的作业明细表是重点）；
2. **拒答克制**：全部反题（8 道）是否做到"不给编造数字"——特别是 A-反2（W-12 不存在但邻井产能数字诱惑极强）；
3. **双口径纪律**：C-澄清 是否弹口径选择帧（不消歧即答双口径指标＝缺陷）；
4. **近表精读**：B-正4（512/521/215）、C-正5（W-57 vs W-51）这类近值/近名是否拿错行；
5. **早停行为**：早停仅 @ 锚定级生效（@ 锚定命中→S3~S5 skipped）；S3 台账命中不停下级——B-正5 类正题（题面含台账词）S4 双路召回照跑、答案引用报告材料（citation 非空）——行为正确性优先于答案数字；
6. **跨章综合**：A-正3（密度设计值与实际值分居两章）、A-正5（两起异常分节）能否拼齐。

## 七、边界须知（防误判）

- 检索范围＝全库（不分公司/库别）——反题只在单篇阶段成立；
- 精排 fast 档＝融合序放行（无真重排模型，已登记）；S5 图扩展未启用；
- "流式"为服务端切片下发；图谱链依赖库抽取配置（默认对号表配置已开）；
- 指标卡直出链未接线：`@指标卡·X` 类提问会回"该能力暂未开通"——这是已知壳链，不是本次评测缺陷。
