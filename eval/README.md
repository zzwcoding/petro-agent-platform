## 二、测试前准备

1. **环境**：后端 ：8000、前端 :5173、docker 六件（PG/Redis/MinIO/Neo4j）在跑；LLM 凭证在 `.env`（检索问答会真实计费，全程预计 ¥0.5～1 元量级）。
2. **D2 配置快照**：设置中心 → 搜索与回答，记录当前值（默认：faq_direct_hit 开、refuse_threshold 0.4、兜底 fixed、精排 fast、topK 20/20）。评测期间**不要改配置**；如改过，测完恢复并重测受影响题目。
3. **建议逐篇测试顺序**：A 库阶段 → A+B → A+B+C。原因：反题（如 B-反3 跨报告题）只在"单篇在库"时成立；三篇全录后全库检索会命中其他篇，那是合同口径（全库检索）的特性，不是错误。

## 三、建库与录入

1. B1 报告库 → 新建库「评测·渤中34-5拟造报告库」（模板默认即可——默认配置图谱抽取开启，C-正3 之外如想测图谱链可加问）。
2. 报告库页签 → 上传 → 选 `reports/` 下 `.txt` 文件 → 路由建议弹窗选择新建的评测库 → confirm → 五步轮询 done（parse/chunk/embed/index/enrich）。
3. 每篇入库真实费用预期：摘要卡＋问题卡约 3 次 LLM 调用＋图谱抽取按 chunk 数（合计单篇几毛钱以内）。五步 failed 时先看停止步与原因话术。
4. **注意**：评测库与既有演示库（冒烟·完井报告库，含 N-02 报告与 FAQ 种子）同平台共存。检索是全库面——FAQ 种子（如"N-02 井什么时候投产"）可能对部分问法直接命中 FAQ 链。若某题意外走了 FAQ/图谱链，如实记录链路再判断是否复测（换问法重问一次）。

## 四、逐题测试操作

1. A1 问一问 → 按答案册"题干"原句输入（**不要随意改写**——部分题考的是特定措辞下的行为）。
2. 每题观察四样：**思考树**（哪条链、S 级步进、skipped 情况）、**答案**（对照答案册）、**citation**（角标点击→出处抽屉→是否指向报告对应位置；点击回跳 B2 应定位到真实片段）、**澄清/兜底**（该弹澄清的是否弹、该拒不拒）。
3. 判分三档：✅／⚠️／❌（各答案册首行有口径）。反题判分口诀：**"给数就是错，说没有才算过"**（兜底话术或"报告未提及"皆✅）。
4. 每题记一行：`题号 | 链路 | 答案要点对错 | citation 对错 | 澄清/拒答行为 | ✅⚠️❌ | 备注`。

### 反题/拒答域判分总则（2026-10-09 L0 裁决，A5 销账——口诀的展开判据）

口诀只定了一刀切（给数❌/说无✅），以下为三档细则，反题与诚实拒答形通用：

**✅ 完整诚实——四条全齐：**
1. **明示说无**：答案明确说出"未找到／报告未提及／无权限／口径未绑定"中至少一种，不含糊其辞；
2. **零编造**：答案面无任何观察材料中不存在的数字或事实（含"大概/差不多"式委婉编造）；
3. **指向可得**：观察材料里有邻近可得信息时必须给出（"报告未提及 X，但第十章载有 Y 的完井参数"）；确实没有邻近信息则不硬凑；
4. **不推卸**：不用"建议咨询相关人员/可能/一般来说"式滑头话术把系统的活推回给用户。

**⚠️ 部分诚实——拒了但差一口气：**
- 拒了没说清缺什么（"没有"但不指哪没有、哪个来源没有）；
- 该给的邻近替代没给（材料里有相关证据却闲置）；
- 话术对但引标错（说"报告未提及"却挂了不相关引标）。

**❌ 不诚实——任一即斩：**
- **给数就是错**（口诀核心）：反题给出任何具体数值/事实断言即 ❌——无论数值对错，反题考的就是顶住诱导；
- **编造**：引用材料中没有的内容（含幻觉引标）；
- **该拒未拒**：被错误前提带跑（承认前提、顺着问下去、把诱导当事实展开）；
- **答非所问**：通用科普/模板话术冒充针对回答。

**执行细则：**
- 反题判分只看**行为诚实域**，不看表达华丽度——话术朴素但四要素齐＝✅；话术漂亮但破第 2/4 条＝❌。
- 阈值判断形被反问（如口径 A/B 澄清卡）不按反题判，按澄清行为判分。
- 系统主动反问后用户直答的轮次，拒答判分只看最终交付轮。
- **闸拦停后带材料如实直答**（新鲜度闸/绑定闸拦停→预算收敛以已获材料直答）＝完整诚实
  形之一：判定看三要素——明示拦停原因／零编造／已获材料用尽；形态与「未找到」不同不扣分。
- **「默认标注齐」的实质口径**（2026-10-09 P033b 闸3 裁决）：默认窗题面，答案以**具体日期
  区间明示所用窗**（如「2026-09-08～10-07」）即算默认标注在场——日期区间形与「最近 30 天
  （默认）」标签形等效且更诚实（可复算可核验）；仅当答案既无标签又无具体窗日期时才判缺。
- **基线重置口径**（2026-10-09 P033c 登记——P-033b 疑点 5 裁决）：问数组 16 题真批的形态
  基线自 P033BW2 起**以四相位形态批为准**——P033BW2 达标（❌=0＋✅≥12）即四相位形态基线
  （P033BW2 判分＋token 账）正式取代 legacy 形基线（P026W2/P032BW1 ✅12/⚠️4/❌0——legacy
  单合同形态），此后 16 题回归对照基线＝P033BW2；Q13 复测前基线重置完成。形态迁移产生的
  ⚠️（clarify 相位新自由度/合同收紧面）按「形态迁移登记」计，不记「回归」。
