- **考试日期**：2026-10-17
- **被测系统**：WeKnora Lite v0.8.3（单机二进制，SQLite + 内存队列），自定义 agent `petro-eval-agent`（quick-answer 模式，max_completion_tokens=32768，仅绑定评测知识库，关闭联网）
- **聊天模型**：MiniMax-M3（与 petro-agent Q17 冻结点同款，OpenAI 兼容端点 api.minimax.cn/v1）
- **向量模型**：nomic-embed-text:latest（Ollama 本地，768 维）

## 三、病因 triage（按危害排序）

**① 检索片段未进窗 → 错误缺位声明（最大病因，1 个 ❌ 直接致因 + 大量 ⚠️）**
答案在库里，但对应章节未被召回，WeKnora 断言"材料中没有"而不是扩大检索。典型：B-正4（W-21 检泵周期 512 天在第三章明细表首行，系统称"材料中未给出"→❌）、C-正4（酸化四要素全在第四章→❌）、NQ-M10（五组数据全在 202701 月报 3.1/3.2 节，检索只达完井报告→❌）、NQ-M1/M9、D-诱1（443 天在 B 报告 :48 明文却称"查不到"）、D-诱3（−125.4/扩大 3.2 同病）。WeKnora 的检索 top_k 偏小（回答自述"仅返回 5 条候选片段"），对分散在多章的复合题召回不足。

**② 同型文档判源失败（❌：NQ-C2、NQ-C10）**
库内两份同构的完井工程报告（A-W11 与 Y-21），WeKnora 答题时静默拿错报告的章节结构/成分数据，未察觉也无标注。petro-agent 有 slots 锚篇机制（题面锚定报告），WeKnora 检索问答链无此能力。C2 甚至把 A-W11 的章节结构套到 Y-21 报告上并编造"报告内部不一致"的调和解释。

**③ 判分总则 v2 分油田覆盖面缺失（约 13 个 ⚠️）**
总则 v2 要求"未点名油田/井号范围的题＝跨油田全覆盖"。WeKnora 单次检索召回有限，普遍只答一个油田（多为检索命中的那一套），出处如实标注但无分源结构——按 v2 落 ⚠️（答案不完整）。涉及 A-正2/正3/正7、B-正1/正2/正5、C-正2/正3/正6、C-反1、D-诱9、NQ-M3、NQ-C3/C4 等。这是 WeKnora ⚠️ 偏多的最大单一因素。

**④ petro 特有系统机制缺失（系统级 5 题的主因）**
系统-禁用词（❌）：petro 有"老完成率"安检拦截 + 出路指引，WeKnora 当普通问句放行作答；系统-术语躺井/届满（⚠️）：petro 有台账词条卡 + 已届满漂移标注，WeKnora 走通用定义；系统-FAQ秒回（⚠️）：N-02 报告与 FAQ 种子不在评测库（环境前提差异，判分轴按交付正确判）。这 5 题考的是 petro 的产品能力，对 WeKnora 属"装备差"而非"答错"，但按同一标尺如实记分。

**⑤ 个别数值/折算错误（❌：NQ-D6、NQ-D9、NQ-D10）**
D6 自行折算把 18 m³/d 答成 1.8（万吨误作吨，错 10 倍）；D9 断言"原文并无此表述"与原文相悖；D10 被反题诱导折吨值"给数就是错"中招。

## 四、WeKnora 的亮点

1. **诚实性满分**：全部 81 题无一幻觉数值——评卷子代理对答案册未载的补充数值逐条 grep 源报告核验，全部属实。
2. **诱导反题全线守住**：D 组 15/15 识破错误前提，反题口诀"给数就是错，说没有才算过"执行到位，近值干扰（295/428/512）、近名井号（W-42/W-45）、诱导折算（0.89 折吨）几乎全部未中招（仅 D10 一题例外）。
3. **引用真实**：`<kb doc chunk_id>` 引用标记指向的报告与片段全部核验属实。
4. **双口径并行披露**（C-澄清、D-诱5）：主口径与检修剔除口径并列表述，与报告原文口径纪律一致。
5. **缺位时明示**：检索不到时明说"未检索到"并指向数据属地，不硬凑——这正是反题要考的行为。

## 五、公平性注记

1. **配置修复轮**：首轮 WEK1 用 WeKnora 默认链路，输出预算 2048 token 导致 22/81 题思考段截断、正文为空（该批已存档 `存档-WEK1-默认2048预算/`）。修复＝自定义 agent 调至 32768 后全量重跑（WEK2，本报告依据）。这属于部署配置问题，与 petro 评测多轮"修复→复测"的台账惯例一致。
2. **无冻结时钟**：WeKnora 运行在真实时钟 2026-10，题面"今年/去年"按真实时间解释；因月报语料自带绝对日期（202608/202701），本次实际未产生时钟偏差判分（判分组确认本批无时钟差异题）。
3. **判分口径对齐**：与 Q17 完全同一套答案册、判分三档、反题总则、判分总则 v2（分油田全覆盖）与判分轴执行，判分前逐数值回查源报告。petro 特有机制（思考树/台账/FAQ/slots）对 WeKnora 不可见，按答案面判分并在 note 中标注。
4. **两处存疑判分**：A-反3（⚠️ 可辩 ✅）、NQ-M10（❌ 为严重度阶梯推定，具名形态未踩中）、NQ-D1（⚠️ 具名档 2~3 组，实答 1 组）——均已在判分文件 note 中标注，供复核。

## 六、结论

同模型（MiniMax-M3）同题库同判分标尺下，WeKnora Lite 在 81 道知识题上拿到 **✅34/⚠️36/❌11**，可用回答率 86.4%（petro-agent 为 97.5%）。差距不在模型也不在诚实性（零幻觉、反题全守住），集中在三点：**检索召回不足**（top_k 小、多章复合题片段进不了窗）、**多文档判源/分源能力缺失**（同型报告张冠李戴、无分油田覆盖意识）、**缺少 petro 的领域中间层**（拦截规则、台账词条、澄清帧、锚篇 slots）。前两点可通过调大检索窗口/引入重排序/多轮检索改善，第三点是产品形态差异。
