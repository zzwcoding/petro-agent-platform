## 0. 先读这里：名词与判分口径

| 词 | 含义 |
|---|---|
| 题集 | 一批固定题目＋标准答案（答案册），用于测系统答得对不对。题干原句照录、不许改写。 |
| 判分三档 | ✅ 答对且证据齐；⚠️ 部分对（如只答了单套数据、出处标错）；❌ 答错/编造/该拒不拒。 |
| 帧（SSE frame） | 系统回答过程中服务器逐条推送的事件记录。跑批把每题的帧全量存档在 `eval/results/frames/`，判分以帧为准，不凭肉眼。 |
| 病灶 | 反复出现的缺陷类型（如"检索漏召回""张冠李戴"），按族登记编号（A5、E9……）。 |
| 挂账 | 已登记、还没修的问题，带归属票号，不许静默丢弃。 |
| V1 / V2 | V1＝第一版问答实现（多链流水线）；V2＝重写的第二版（appv2，六步循环→ReAct 自主循环）。 |
| 跑批 | 用脚本把题集整批自动问一遍（`eval/results/tools/rerun.py`），纪律：每题只问一遍、零重试、帧全存档。 |
| 锚值 | 题册里钉死的数值（如 Z-16 井年产量 5839.63 吨），用来机判答案对错。 |

**判分总则的四个版本**（判得对不对先看口径）：
1. **v1 三档**＋反题口诀「给数就是错，说没有才算过」（`eval/README.md`）。
2. **v2 跨油田全覆盖**（2026-10-06，提交 9a9b17f）：题干没点名油田的题，正确答案必须覆盖库内所有油田、分油田列明；只答一套＝⚠️，跨套混写＝❌。
3. **同型文档裁决**（2026-10-07）：库里有两份同型报告时（如 A-W11 与 Y-21 完井报告），引用错报告＝张冠李戴 ❌；分源如实阐述、不调和矛盾＝✅。
4. **反题/拒答域总则**（2026-10-09，提交 412c691，A5 销账）：✅ 四要素（明示说无／零编造／指向可得／不推卸）、⚠️ 三形、❌ 四斩，落 `eval/README.md`，作 Q13 判分依据。
