- `set`：`"97"`｜`"50"`；`book`：子册名；`family`：问数组族/新语料题型（可 null）；`dimension`：员工模拟 12 维度（可 null）。
- `question`：**题干逐字**（不改写——诱导配方在特定措辞下才成立）。
- `expected`：预期行为（路由/链路/是否拒答/是否反问）。
- `answer_ref`：标准答案出处（仓内路径＋锚点）；员工模拟 50 题为 `eval/suite-147/answers/50-员工模拟.md#Qxx`。
- `scoring_ref`：判分档出处；统一总则见 `scoring.md`。
- `sources`：语料真源文件（相对仓根）；行为题可空。
- `status`：`ready`（答案与判分齐）｜`needs-owner`（缺口/需 Owner 确认，附 `note`）。
