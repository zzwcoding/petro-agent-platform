**1. 发送接线（中栏真流贯通）**——A1V2R 输入区：
```
const [turns, setTurns] = useState([])      // FE-03/04 已在用的会话数组，本票接真提问
const [sending, setSending] = useState(false)
const askStartRef = useRef(null)            // 本地计时起点（Owner 拍板：无权威耗时）

send(question) {
  if (!question.trim() || sending) return
  setSending(true); askStartRef.current = Date.now()
  turn = newTurnV2('ask', question)
  setTurns(ts => [...ts, turn])
  postAskV2({ question }, handlers({
    onFrame: f => dispatchTurn(turn.runId ?? 占位, f),   // session 帧前先按引用更新：
        // 实现＝setTurns(ts => ts.map(t => t===turn ? reduceV2Frame(t,f) : t))——同对象引用替换
    onDone: () => 收口清 runningRun 键,
    onError: pkg => dispatchTurn(turn, {event:'error', data:pkg}),   // 落 errorFrame
    onTransportError: () => dispatchTurn(turn, {event:'transport'})  // closed='transport'（既有枚举）
  })).finally(() => setSending(false))
}
```
- 追问：输入框旁「继续本会话」语义＝`postAskV2({question, followupRunId: 上一轮 runId})`（前轮须 completed，后端 409 时页面 Alert 透传 message——契约 chat.py:90-105）。
- 时长：closed 时算 `Math.round((Date.now()-askStartRef.current)/1000)` 写入页面临时面 `durationByRun[runId]`，RunMetaLine/摘要行按 runId 取——不入 TurnShape（形状无此键）。
