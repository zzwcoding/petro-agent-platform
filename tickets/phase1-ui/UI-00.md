### 一、新增 PagedTable（〔来源：方案 §2.1/§5-壳层-1〕；SHELL 审查发现 F2「统一分页组件尚不存在，14 张业务集合表无落位载体」）

1. 新增 `web/src/components/PagedTable.jsx`（组件形态，非 hook——方案 §2.1 选型定死），props 契约：
   - `dataSource/columns/rowKey/loading` 透传；`emptyText` **必填**（string｜node）；
   - `error`（ApiError|null）：非空时空态描述换 `errorEmptyText`（缺省值「数据拉取失败」）；
   - `resetKey`（string｜number）：变化时 client 模式页码归 1（筛条件联动）；
   - `mode` 默认 `'client'`；server 模式受控四件 `page/pageSize/onPageChange/total`；
   - 其余 props（expandable/onRow/rowClassName/scroll/size 等）全透传。
2. 分页条参数定死：`showSizeChanger=false`、`showQuickJumper=false`、`hideOnSinglePage=false`（统计恒显）、`showTotal = t => 共 ${t} 条`、位置默认右下、`size='small'`；pageSize 默认 20（对齐后端 `ReadOnlyRepository.paginate` 的 `page_size: int = 20`——app/infra/db.py:395 实读；`Page[T]` 数据类字段无默认值，db.py:145 仅类声明）；server 模式 pageSize 必传（D1 流水=15 合同冻结）。
3. 空态渲染定死：`Empty image={Empty.PRESENTED_IMAGE_SIMPLE}`＋description=emptyText；error 非空换 errorEmptyText。**不接受 `locale` 覆盖 emptyText**（实现上收掉或忽略 locale 的 emptyText 键，取舍写进文件头注释）。内联 Alert 由页面自挂——失败态≠空态，两件并存，不进封装。
4. client 模式：内部 useState 页码对整表 `dataSource` 内存切片；`resetKey` 变化归页 1；**内置超界钳制定死**——渲染时当前页超出总页数自动归页 1（显式 resetKey 覆盖不到的隐式筛变兜底，如 B5 图例隐去边、弹窗内数据切换）。
5. server 模式：页码/页大小全受控，`onPageChange(page, pageSize)` 上抛（迁移母本＝D1 流水现形状 `D1.jsx:455-465`）。
6. 文件头 JSDoc 挂标签 `DEBT(阶段1-ui/UI-07)`——client 模式＝临时客户端分页、全部去向 UI-07；标签形态实跑过债闸（方案 §2.4 实测 resolve_target('阶段1-ui/UI-07')→True；字面 `DEBT(UI-07)` 会红，禁用）。本批唯一新增 DEBT 标签就在此一处，不在各页散布。
7. 新增 `web/src/components/PagedTable.test.jsx`（文件头 `/** @vitest-environment jsdom */`——全仓测试环境约定，B1.test.jsx:14 实读），五组断言逐组落：
