# UI-12 中间表格表内滚动（Owner 裁决——有中间表格的页面表格内滚、页面不滚）

任务: Owner 2026-10-05 巡检裁决：凡页面中间有大表格的，表格自己做内部滚动（表头、工具栏、分页条恒在视口内），**页面级滚动消灭**（实测基线：B2 页滚 2274px、B3 页滚 409px；B1/D1 当前数据短未溢出但按结构性规则一并改）。做法定死：`PagedTable` 增 `fill` 模式（ResizeObserver 测高→`scroll.y` 内滚），各页搭「root→Card→body→Tabs→pane→工具栏→PagedTable」flex 链。范围＝五落地页全部 PagedTable 表（B1 台账/任务/库管理、B2 片段/复核、B3 问答、D1 四页签、B5 关系清单）；A1 无表不动；原型快照禁改。

改造项（逐项定死）:
1. PagedTable.jsx 增 `fill` prop（默认 false 零回归）：fill 时外层包 `<div style={{ display:'flex', flexDirection:'column', flex:1, minHeight:0 }} ref={wrapRef}>`；`const [y, setY] = useState()`；`useEffect` 挂 ResizeObserver（`typeof ResizeObserver === 'undefined'` 时跳过——jsdom/兜底安全）测 wrapper 高度，`scrollY = wrapH − thead高 − pagination高`（从渲染后 DOM `.ant-table-thead` 与 `.ant-pagination` 实测；观测回调里随窗口/内容变化重算），传 `scroll={{ ...(原 x), y: scrollY }}`；thead/pagination 尚未渲染时首帧先不传 y（observer 回调补挂）。文件头 JSDoc 补 fill 契约说明。
2. PagedTable.test.jsx 新增 fill 直测：stub `window.ResizeObserver`（捕获回调、手动触发），断言①observer 已挂且观测 wrapper②回调触发后 Table 获得 scroll.y③未传 fill 时行为与现基线逐字节一致（零回归锚）。
3. web/src/index.css 增共享工具类 `.fill-tabs`：
   `.fill-tabs{display:flex;flex-direction:column;flex:1;min-height:0;}` `.fill-tabs>.ant-tabs-nav{margin:0 0 12px;}` `.fill-tabs .ant-tabs-content-holder{flex:1;min-height:0;display:flex;flex-direction:column;}` `.fill-tabs .ant-tabs-content{flex:1;min-height:0;height:100%;}` `.fill-tabs .ant-tabs-tabpane{height:100%;}` `.fill-tabs .ant-tabs-tabpane-active{display:flex;flex-direction:column;min-height:0;}`
4. B1.jsx：root→Card→body→Tabs→pane flex 链——Card `style` 改 `{ flex:'1 1 auto', minHeight:0, display:'flex', flexDirection:'column' }`＋`styles={{ body:{ flex:1, minHeight:0, display:'flex', flexDirection:'column', overflow:'hidden' } }}`；Tabs 加 `className="fill-tabs"`（activeKey/onChange/items 不动）；三个 pane 内工具栏行（保持原样）之下把 PagedTable 全部加 `fill`。
