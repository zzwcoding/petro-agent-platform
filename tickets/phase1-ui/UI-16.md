# UI-16 前端设计令牌层与落地树视觉改造（refactoring-ui 落地）

> **票型说明**：本票为**追认归档票**——施工由 Owner 在会话中直接拍板推进（先审后改、
> 拍板三处范围与取舍），票面于施工完成后按实际落地形态补写归档，作为决策的持久留痕与
> 后续施工依据。**票面所载改造项与验收判据均取自实际落地结果，非事后补写的空话。**

任务: 全站前端此前**没有设计系统**——1421 处内联 `style={{}}`、526 个手写 hex、约 60 个
去重色值、8 档字号（10/11/12/13/14/16/18/24）、19 个 line-height、13/15/10 档 padding/margin/gap、
31 档控件高度、18/18 页在 375px 横向溢出、18/18 页 h1 数量为 0。根因不是「忘了加变量」：
**源码作者写的是 antd 亮色主题的色值，而 antd 的 `darkAlgorithm` 会把每个语义色重新派生一遍**
（种子 `#4a9dff` → 渲染 `#4288dc`；源码 `#52c41a` → 渲染 `#49aa19`；`#faad14` → `#d89614`；
`#ff4d4f` → `#dc4446`），于是每个语义色分裂成「源码值」与「渲染值」两套系统。

本票按 `refactoring-ui`（Adam Wathan / Steve Schoger）的层级、间距、排版、颜色、深度五律落地：
**① 建令牌层**（在算法层把整套令牌钉死，让 antd 渲染值 === 源码既有值，一处改动全站收敛）；
**② 落地树 10 页色值/字号归令牌**；**③ 壳层层级与响应式**；**④ 表格可扫读性**；
**⑤ 动作金字塔**。原型树（`web/src/pages/**`）**零触碰**（AGENTS.md 硬纪律 0 ＋ 原型保护闸），
但因 `ConfigProvider` 与 `index.css` 两树共用而自动吃到令牌红利。

先读:
- `web/src/main.jsx`（原 `ConfigProvider` 三行内联 theme——本票令牌层落点）
- `web/src/shell/{Shell,SideMenu,HeaderBar}.jsx`（壳层：树语境、导航、页头）
- `web/src/landing/{A1,E2}.jsx`（样板页：对话型 / 信息密集型）
- `web/src/landing/B5.jsx`（G6 关系图谱——canvas 渲染器，色值不可用 CSS 变量）
- `web/src/index.css`（全站唯一样式文件）
- `web/POLISH-SPEC.md`（页面整理规范——呈现形态的依据；功能定义不归本票）

改造项（逐项定死）:

1. **令牌层**（新增 `web/src/theme.js`）：`palette` 为唯一真源，分 `surface`/`text`/`brand`/`sider`/`viz` 五组；
   - `pinDarkPalette(seed, prev)` 作为第二个 algorithm 钉死派生结果。
     **签名必须是 `(seed, prev)`**——cssinjs 的 `derivatives.reduce` 调的是 `r(e, t)`，
     第二个参数才是上一步的输出；写成 `(t) => ({...t})` 会把 seed 当 prev，派生链直接断掉
     （`colorBorder` 等全变 `undefined`）。
   - `colorTextLightSolid` / `colorWhite` 走 `token` prop 而非 algorithm——`alias.js` 会在派生**之后**
     用 `colorWhite` 重算它，algorithm 里钉死会被覆盖。
   - **主按钮翻转对比**（§5.6.1）：白字 on `#4a9dff` 仅 **2.78:1** 不达标；深字 `#0d1117` **6.81:1** ✓。
     故主色底 + 深色字，选中菜单项同此语言。
   - **表面三层**：`#0d1117`（页面）/ `#161b22`（卡片）/ `#212830`（浮层）——消除改造前
     body `#0d1117` 与 antd 卡片 `#141414` 之间的可见接缝。
   - **文字三级**：`rgba(255,255,255,.85)` / `rgba(255,255,255,.65)` / `#8a94a3`（三级沿用项目既成值
     287 处，卡片底 5.64:1），第四级 `rgba(255,255,255,.25)` 仅限禁用态。
   - **菜单分组标题**须显式给定 `darkGroupTitleColor`：antd 暗色菜单的分组标题默认取
     `colorTextLightSolid`，本项目把它翻成深色后，标题叠在品牌蓝侧栏上对比度仅 **1.28:1**（几乎不可见）。
     定为 `#8aa2c0`（侧栏同色相）= **5.17:1**，且明显暗于菜单项 8.27:1（层级保留）。
2. **CSS 变量**：同源注入 `:root`（`--pa-*`），`index.css` 的 body/`.code-block` 改走变量，
   杜绝「CSS 的底色」与「antd 组件的底色」再次漂移。
3. **落地树 10 页归令牌**：手写 hex → `var(--pa-*)`；字号 10/11/13 → 12、15 → 16、26 → 24。
   **只改颜色与字号**，不动文案/逻辑/结构/间距。
   - **数字形态 rgba 亦须处理**：`rgba(22,119,255,…)` 用的是 antd 旧默认蓝 `#1677ff`，
     与品牌蓝不同源——hex 扫描抓不到，须一并换成 `rgba(74,157,255,…)`。
4. **壳层**：
   - 侧栏组织模式**保持原样**（落地项与原型项同组并列、每个原型项带「原型」角标）——
     双树对照是 `frontend-foundation §4` 的刻意设计，**不因视觉改造而改组织**。
     层级靠**权重差**表达：原型项整体降一级文字色（`.menu-proto`），悬停/选中恢复全亮。
   - 角标 10px → 12px（实测全站 342 处 10px 文字，低于可读下限）。
   - 侧栏窄屏（<lg 992px）自动折叠，页头开关可展开——改造前固定 216px 永不折叠，
     实测 18/18 页在 375px 横向溢出（单页 91 个元素越界）。
   - 页标题落 `<h1>`（改造前 18/18 页 h1 数量为 0）。
5. **表格可扫读性**：长文本列 2 行截断＋Tooltip 挂全文（`components/ClampCell.jsx` 共享件，
   E2/B3/B4 三页共用）。**内容一字不删**，只把「需要展开才知道」的细节收进悬停层。
6. **动作金字塔**（§2.8）：表格行内 icon-only 按钮由默认带边框样式改 `type="text"`。
   工具栏/抽屉/弹窗内按钮与带文字的按钮**一律不动**。
7. **G6/canvas 颜色纪律**（`palette.viz`）：G6 v5 默认 **canvas** 渲染器，
   `fill`/`stroke`/`labelFill`/`iconFill`/`background` 走 canvas 2D 上下文或 SVG 属性，
   **CSS 变量在那里不解析**——实测把画布底与节点文字改成 `var(--pa-*)` 后，画布变纯黑、
   节点主文字整段消失、边标签不显。故凡进 G6 配置的颜色一律取 `palette.viz` 的**字面 hex**；
   DOM 侧（tooltip 浮层、图例色点）仍走 CSS 变量。
   图谱按节点类型着色的分类色（井/区块/平台/油田/措施 ＋ 未知类型轮转）**独立成一套**——
   这一套的职责是互相区分，若都映射到 `--pa-primary`/`--pa-success`，不同类型会撞成同一色。
8. **设计令牌闸**（新增 `tools/check_design_tokens.py`，挂 CI frontend job）四道检查：
   ① `web/design-tokens.json` × `web/src/theme.js` 同步；② 对比度矩阵（WCAG §5.6，正文 4.5:1）；
   ③ 暗色令牌落地齐全；④ **G6 图形属性里禁 CSS 变量**——按**槽位名**判定
   （`*Fill`/`stroke`/`haloStroke`/Graph 根层 `background`），不误报 tooltip 那套 DOM 样式。
9. **文档**：`web/DESIGN.md`（系统手册，含三条已知边界：antd 预设色板钉不住 / G6 canvas 不解析
   CSS 变量 / 可视化分类色独立一套）；`web/README.md` 同步侧栏组织模式说明。
