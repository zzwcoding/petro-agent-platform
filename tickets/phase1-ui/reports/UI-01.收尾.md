## 七、web-eslint 闸红复盘（合入前闸机报红——随票补闸修复）

- **实录**：合入前闸机报 `web-eslint` exit 2，错误尾部＝`Error: ENOENT: no such file or directory, open '.../web/vite.config.js.timestamp-1791086269328-88c3b3e086f67.mjs'`（at readAndVerifyFile, eslint-helpers.js:1306）。
- **根因（机证复现）**：vite/vitest 装载配置时写 `vite.config.js.timestamp-*.mjs` 临时文件、装载完即删；web/eslint.config.js 旧 ignores 仅 `dist/`、`node_modules/`，而 files 匹配 `**/*.{js,jsx,mjs}`——临时文件在扫描期被收列、读取前被 vite 删掉即 ENOENT exit 2。**暴露路径实证**：构造同名 dummy 文件（内容 `var x = 1`）实跑 `npm --prefix web run lint` → ESLint 对其报 `no-unused-vars` error、exit 1（证明该形态确被 lint 收列，非读偶然）；随即净树复跑 exit 0（红＝瞬态竞窗，非代码缺陷，本票两文件改动与该闸无关）。
- **修复**：`web/eslint.config.js` ignores 补 `vite.config.js.timestamp-*.mjs`（gitignore 语义无斜杠模式全深度匹配）。**修复实证**：dummy 仍在盘面时 lint exit 0（0 error/2 warning——文件已被排除、不进 lint 队列，瞬存瞬删均无从 ENOENT）；删除 dummy 后净树复跑 exit 0（基线不变）；终树全套闸复跑全绿（见门禁表）。
- **定性**：闸机环境竞窗（vite 临时文件生命周期 × lint 目录扫描）暴露的闸基建缺口，非票面代码回归；修复属 lint 配置单行，lint 规则集与告警基线零变化。
