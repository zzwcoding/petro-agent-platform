## 四、执行差异登记（票面未点名而为达成票面目标所必须的改动，逐条申报待主窗/Owner 裁）

1. **页根 `minHeight:'100%'` → `height:'100%'`（B1/B2/B3/D1 四页）**：票面改造项 4–7 只点名 Card/body/Tabs/PagedTable，但 flex 收缩链需要页根**高度有界**——`minHeight:'100%'` 时页根随内容长高（flex 容器高＝内容高，无收缩可言），Card 永不收缩、fill 测得自然高、内滚永不生效、页面照滚，与 Owner「页面级滚动消灭」裁决及验收「页面滚动量=0」直接矛盾。故四页页根补 `height:'100%'`（链首节），B5 不在页根链范围（右栏 578 定高行自洽）未动。**若主窗裁决不许动页根**：页面级滚动消灭不成立，需回设计仓改票。
2. **D1 params 页签（无表格）加内滚容器** `flex:1 minHeight:0 overflowY:auto`（表单＋yaml 全文联体滚）：票面未点名该页签；不加则长 yaml 被 body `overflow:hidden` 截断不可达——「页面不滚」不等于「内容丢」，此为必要配套。
3. **D1 演练日志区 div 转 flex 链**（`flex:1, minHeight:0, display:'flex', flexDirection:'column'`，原 marginTop:16 保留）：pane→表格中间层贯通，否则日志表 fill 测得自然高、长日志溢出被截。
4. **B5 清单容器保留 `overflow:auto`**：票面第 8 条「把清单容器改 flex 链」已照办（加 display:flex column）；overflow:auto 留作无 ResizeObserver 环境（jsdom/老内核）兜底——fill 生效时 wrapper 与容器同高不产生第二道滚动。
5. **B2 详情弹窗内滚（UI-03 T10 定稿）与 B5 选句清单内滚（UI-05 T11 定稿）未随之改**：弹窗层不属「页面中间大表格」，票面未点名，既有定稿优先。
