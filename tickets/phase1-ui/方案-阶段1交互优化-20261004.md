## 2. 表格分页统一方案

### 2.1 封装形态定死：组件 `web/src/components/PagedTable.jsx`（非 hook）

选型理由：hook 会把 locale/showTotal/Empty 形态留在每页各写一遍，正是现状不齐的根源（B2 纯字符串空态、B3 主表无 locale）；组件把分页形态与空态形态锁成一处，antd Table 其余 props 全透传，测试耦合面（expandable/rowClassName/onRow/scroll）不变。

```jsx
<PagedTable
  dataSource columns rowKey loading          // 常规 Table props，透传
  emptyText                                   // 必填 prop（string | node）——强制每表想清空态话术
  error={ApiError|null}                       // 可选：非空时 emptyText 自动换 errorEmptyText
  errorEmptyText                              // 缺省「数据拉取失败」
  resetKey={string|number}                    // 可选：变化时 client 模式页码归 1（筛条件联动）
  mode="client" | "server"                    // 默认 client
  page pageSize onPageChange total            // server 模式受控四件
  {...rest}                                   // expandable/onRow/rowClassName/scroll/size 等全透传
/>
```

- **pageSize 默认 20**（对齐后端 `ReadOnlyRepository.paginate` 的 `page_size: int = 20` 默认——实测 app/infra/db.py:390,395（`grep -n` 实跑：390＝`async def paginate`、394＝`page: int = 1`、395＝`page_size: int = 20`）；评审指正：`Page[T]` 数据类字段本身无默认值，db.py:145 仅类声明）；server 模式 pageSize 必传（D1 流水=15 合同冻结，`D1.jsx:111`）。
- **分页条参数定死**：`showSizeChanger=false`（本批不做页大小切换——各册 pageSize 语义冻结不一，开启随 UI-07 按册裁决）、`showQuickJumper=false`（当前量级页数个位数，跳转控件是噪音）、`hideOnSinglePage=false`（统计恒显）、`showTotal = t => 共 ${t} 条`（与 D1 流水表现文案一致，`D1.jsx:460`）、位置默认右下、`size` 默认 `'small'`（全站现状）。
- **空态渲染定死**：`Empty image={Empty.PRESENTED_IMAGE_SIMPLE}`＋description=emptyText；`error` 非空时 description 换 errorEmptyText。内联 Alert 仍由页面自挂（错误块不属表格封装职责——失败态≠空态，两件并存）。
- **client 模式**：内部 `useState` 页码，对整表 `dataSource` 内存切片；`resetKey` 变化归页 1。**内置超界钳制定死**：渲染时 current 页码超出总页数自动归 1——筛选缩短数据后停在超界页出空表的兜底，显式 resetKey 覆盖不到的隐式筛变（如 B5 图例开关隐去边、弹窗内数据切换）由此免疫；各表显式 resetKey 绑定另见 §2.2 末总表。
- **server 模式**：页码/页大小全受控，`onPageChange(page, pageSize)` 上抛（D1 流水现形状原样迁移，`D1.jsx:455-465`）。
- PagedTable **不接受** `locale` 覆盖 emptyText——空态话术一律走 emptyText prop。
- **DEBT 单点登记**：`PagedTable.jsx` 文件头注释挂标签（形态见 §2.4）——client 模式＝临时客户端分页，全部去向指向 UI-07；不在各页散布标签。
