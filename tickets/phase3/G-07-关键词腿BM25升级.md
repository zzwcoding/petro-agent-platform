# G-07 关键词腿 BM25 升级（99 册开放问题 5 收口——trigram 代理退役，2026-10-06 开票）

## 背景

1. 合同意图本来就是 BM25：98 kb 卡索引存储缝名＝「向量＋BM25」；BM25 落法悬置为
   **99 册开放问题 5**（tsvector vs 应用层倒排；PG 特有扩展被金仓兼容排除）。
2. 实现仓 P1-04 收尾裁决②选了**阶段 1 代理**：`trigram_coverage`（问句三字组集在片段
   三字组集中的覆盖率，免分词器）——代码注释自带「阶段 1 语义代理」字样。
3. Q3/Q4 评测实证代理失效形态：①三字组无权重层（"W-33"与水词等票）；②三字符连续
   匹配对措辞变化极脆（帧实证关键词腿只回 3~5 条）；③向量腿语料饱和（A 报告片段
   对任意油田问句 0.85+）叠加，五题检索 miss（C-正4/5、D-诱8/12/15）。
4. 关键工程事实：BM25 的数学不需要"词"，只需要"带文档频率的单元"——免分词器理由
   挡得住 tsvector，挡不住应用层 BM25。

## 方案（C1~C4 四笔独立提交）

- **C1 打分器**（kb/domain 纯函数，不接线）：
  - `extract_units`：CJK 二字组滑窗（二字组=中文 IR 免分词器标准单元；三字组对措辞
    过脆是 v1 病根）＋字母数字 token 整取（W-33/SCSSV/2462，含内部连字符）；
  - `bm25_scores(question, texts)`：标准 BM25（k1=1.2/b=0.75 代码常量），IDF 查询时
    现算（df＝含单元的片段数，平滑式 ln((N−df+0.5)/(df+0.5)+1) 自带小语料保护）；
  - `normalize_bm25`：score/(score+K)（K=3.0 代码常量）映射 0~1——**对外分数契约
    不变**（compute_confidence/refuse_threshold/S6 证据分全假设 0~1）。
- **C2 接线**：`index_search` 与 `index_search_dual` 两条关键词腿换打分器＋归一化；
  签名不变；`trigram_coverage` 标注 deprecated（精确子串场景备用）。
- **C3 编号保送**：`index_search_dual` 关键词腿内——问句字母数字 token 在片段
  hit_text 逐字命中、BM25 排名未进 topK 时保送队尾（上限 4）——点名实体绝不缺席。
- **C4 收口登记**：teach 仓 99 册开放问题 5 收口（落法＝应用层 BM25，单元三源，
  DF 查询时现算，分数归一 0~1）；Q5 全量重测落盘。

## 边界

- 不动向量腿／RRF 参数／D2 params／FAQ 相似问匹配／pg_trgm 索引；
- 台账词权重源暂不入打分器（调用方传入需跨 B9 传参，登记为后续增强——编号 token
  与二字组 BM25 已覆盖当前失分面）；
- DF 查询时现算（90 片段量级无压力）；千级语料再登记 DF 持久化。

## 验收

1. 单测：单元切分（二字组/编号 token/单字丢弃）、IDF 稀有度方向（稀有单元压过
   常见单元）、tf 饱和、归一化值域 [0,1)、空输入、保送通道（未进 topK 的编号片段
   被保送、上限 4、已在榜不重复）；
2. 既有 kb/chat 套件回归绿（含 F7 拒答阈值语义）＋mypy/ruff 绿＋两闸绿；
3. 探针：C-正4/5 问句下 W-33/W-57 目标片段进关键词腿 top-10；
4. Q5 全量重测：C-正4/5 改善；A/B 组 21✅ 一题不许跌（防过拟合红线）。
