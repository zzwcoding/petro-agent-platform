## 5. 偏差逐条（现象→原因→处置）

1. **工作树缺 data-plane 仓检出**（现象：PG 集成 fixture 报「DP-03 交付物缺失」）——
   原因：`data-plane/` 是嵌套独立 git 仓（.gitignore 排除），`git worktree` 不携带嵌套
   仓；本工作树 `/Users/divh/Downloads/petro-wt/de01` 无该目录，而既有 PG 测试
   （test_wells_contract_pg.py 等）以 `_REPO_ROOT/data-plane/migrations` 定位交付物。
   处置：验证期临时建符号链接指向主仓检出（不进 git、跑完即删复原），实跑绿后删除；
   提交内容零引用该路径以外的环境。默认闸（不带 TEST_DATABASE_URL）不受影响——PG
   测试按约定 skip。
2. **票面锚点行号漂移**：无实质漂移。票面引 `app/domains/wells/store.py`/`service.py`
   与实码一致（读面 SQL 形状、`WellsStore(db)` 构造形状照旧）；`挂账清单 §E10` 现象/
   修法/实证数字照抄核对无误。
3. **语义细化一处（非偏差，报备）**：票面「返回该表湖当前版批次键（最新 snapshot 行的
   寻址键）」落地为双字段投影——`snapshot_id`（＝raw 行 `_snapshot_id` 的过滤寻址值，
   E10 修法原文「`_snapshot_id = 湖当前版`」）＋`batch_id`（批次键随面携行，血缘/日志
   可读）。「最新」判据＝`snapshot_id` 最大（BIGSERIAL 单调，账本 append-only 追加序即
   版本序；`committed_at` 同源不另作判据）——DE-02 接线时以 `snapshot_id` 过滤即可。
