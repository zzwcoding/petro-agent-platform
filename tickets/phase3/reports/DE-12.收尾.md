## 一、实现（按异常子类区分——不按消息字符串猜）

1. **`app/domains/derivatives/domain.py` 新立 `GraphConflictError(Exception)`**：
   - **独立异常类，不继承 GraphParamError**——409 冲突不是 400 参数错误的子形态，全仓 Conflict 先例同形（KbConflictError/FaqConflictError/RetrievalConflictError 均独立类；quality_task_running/chat_run_state 同口径）；
   - code 恒 `graph_extract_running`（既有族 `<域>_<语义>` 蛇形——faq_scan_running/quality_task_running 重入 409 同族）；
   - message 携带两态文案（「入库支路在跑」/「重抽在跑」——DE-11 登记来源可辨）。
2. **`app/domains/derivatives/service.py` 抛点改 `d.GraphConflictError`**（顶部 `domain as d` 既有 import——DE-11 遗留的函数内 `GraphParamError` import 随抛点改写自然消除，DE-13 E6 验收面）。
3. **`app/api/errors.py` 映射**：
   - 新 handler `handle_graph_conflict`：409＋`error_payload(exc.code, str(exc))`——**错误体形状照抄 409 先例** `handle_drill_conflict`（gateway 演练重入，errors.py:223-228）：`{code, message}` 两键、无 detail 占位；
   - GraphParamError handler 原样（400 族：graph_param_invalid＋graph_ontology_mismatch 带对号明细）；
   - 模块 docstring 错误码清单补 `graph_extract_running` 行（新立值登记挂票面）。
4. **`app/domains/derivatives/__init__.py`**：GraphConflictError 入包导出面（errors.py import 路径）。
5. **`app/api/graph.py`**：reextract 端点 docstring 补 409 注记（端点行为零变更——映射在 errors.py 统一兜）。

409 先例核对（grep 409 app/api/）：gateway_drill_conflict（errors.py:223）、retrieval_conflict（:348）、faq Conflict 族（:317）、quality_task_running（:471）、chat_run_state（:386）——统一形状即 `{code, message}`，本票照抄无发明。
