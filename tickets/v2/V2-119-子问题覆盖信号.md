# V2-119 子问题覆盖信号（程序确定性检测 → 作答上下文显式提示）

## 背景（逻辑）

`explore` 出口已落地（代码＋提示词＋路由＋9 测），但模型**零使用**：它拿不到「某个子问题在材料里零支撑」的信号，且没有义务去核。程序明明可以确定性算出这个信号，却没交给模型。

## 任务：

1. **覆盖检测（程序，零语义）**：执行完成、进入作答前，逐子问题核「其锚/术语/数值记号是否在**渲染窗**内出现」；产出「子问题 → 有支撑/零支撑」表。
2. **显式提示（上下文）**：零支撑的子问题，在作答上下文追加一行，形如：「子问题 {id} 在本次材料中无支撑：可 explore 补充检索，或如实说明未覆盖。」
3. **留痕**：覆盖表落作答步 payload（`subtask_coverage`，additive）。
4. 只做**检测与提示**，不替模型决定是否 explore、不自动改材料。
