## 背景（逻辑）

现作答合同的主指令是「写答案」，`explore` 是附带第二出口（`ANSWER_EXPLORE_CONTRACT`：材料不足以回答时，**除了直接作答，还可以**申请补充检索）。LLM 执行主指令、把「可以」当「可不用」。改法＝把合同结构改成**先核、再决、后写**。

## 任务：

作答合同改为三段式，段序固定（逐字稿见下）：
1. **先核**：逐子问题给「有支撑/无支撑」（与 V2-119 的 `subtask_coverage` 对齐，以程序信号为准）；
2. **再决**：任一无支撑 → 先 `explore`（或如实说明未覆盖）；全部有支撑 → 直接起草；
3. **后写**：起草答案正文。

## 逐字稿（合同段，施工照抄）：

```
【作答前三步】
第一步·先核：对照下方「子问题覆盖表」，逐个子问题给出「有支撑／无支撑」。
第二步·再决：任一无支撑 → 先申请补充检索（explore）或如实说明未覆盖；全部有支撑 → 直接进入第三步。
第三步·后写：输出答案正文。
```
