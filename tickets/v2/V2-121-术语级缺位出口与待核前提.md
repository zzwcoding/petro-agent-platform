# V2-121 术语/对象级缺位出口＋待核前提（S1＋S3）

日期: 2026-10-18 ｜ 依据：`EB11-臆造上下文归因.md`（Q45 编造判定式；正例对照＝「对象级出口 vs 术语级无出口」）；S1＋S3

## 背景（逻辑）

对象级缺位出口存在（材料未覆盖某井/某报告时能如实说没有），但**术语级没有出口**：Q45 问「『措施增油达标』按什么口径算」，合同没有「该口径未在材料中登记」这种合法形，模型只好自造判定式。另：题面里的引述/口语说法被「理解」步当成已确认事实，合同**没有「待核前提」这一格**（Q07/NQ-M8 同因）。

## 任务：

1. **术语级缺位出口**：答案合同增设「该口径/该表述未在材料中登记」的合法形＋示范句（逐字稿见下）。
2. **待核前提行**：首入包增设「待核前提」行，把题面中的引述/口语说法列为待核项，要求先核后答（逐字稿见下）。
3. 正例不受损：`Q43`／`A-反2` 形（引述物是数字或对象）保持既有正确行为。

## 逐字稿（两处，施工照抄）：

```
【术语级缺位出口】若所问口径/表述在材料中查无对应登记，直接写「材料中未见该表述，无法给出其口径」，不得自拟定义或算法。
【待核前提】题面中的引述与口语说法列为本轮待核前提：先在材料中核其是否成立，未成立者如实指出，不得当作已确认事实继续作答。
```
