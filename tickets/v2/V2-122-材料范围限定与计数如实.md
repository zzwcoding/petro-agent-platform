# V2-122 材料范围限定与计数如实（S2＋S5＋S9；并入原 V2-114）

日期: 2026-10-18 ｜ 依据：`EB11-核实.md`（交付面池计数不实：51/51/12 vs 45/63/6）＋`EB11-臆造上下文归因.md` 反向证据（注记披露未见材料却无范围限定指令）；S2＋S5＋S9＋原 V2-114

## 背景（逻辑）

引擎/截断注记**如实披露了「另有 N 条未用进答案」**，但**没有任何指令把断言/否定的适用域限定在已见材料内**——于是出现「明知 47/48 条未见仍下报告级否定」（NQ-M8）与「称 51 条实为 45 条」（A-正6）。计数不实又让「没有任何一条材料提及」的范围本身不可信。

## 任务：

1. **注记改写为范围指令**：引擎/截断注记追加一句对作答面的范围约束（逐字稿见下）。
2. **断言/否定范围限定**：合同明确断言与否定只许锚**已见材料**（逐字稿见下）。
3. **计数如实**：交付面出现的「检索到 N 条／用进 M 条」必须与真实池/窗一致（修 51/51/12 vs 45/63/6 三处）。
4. **分源作答升级**：多来源题的材料段按来源分栏呈现（S9），减少跨源混写。

## 逐字稿（两处，施工照抄）：

```
【范围限定】你的断言与否定只对已见材料成立：不得因「未见」而断言材料中不存在；需说明「本次材料未覆盖」，不得升格为「报告/资料库未载」。
【计数如实】注记中的「检索到 N 条／用进 M 条」为本次真实计数，必须与实际一致。
```
