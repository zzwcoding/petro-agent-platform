# V2-123 材料期 vs 执行日标注（S4）

状态: 待统筹（2026-10-18 记录在案，未排期）
日期: 2026-10-18 ｜ 依据：`EB11-臆造上下文归因.md` E7（「本月」锚 2026-10 而语料只有 2026-08/2027-01；合同对「材料日期晚于执行日」零约束）；S4

## 背景（逻辑）

材料头只标来源与信任级，**不标报表期**；模型无法判断「这份材料是执行日之前还是之后」。Q07（引用 2027-01 月报断言「当前状态」）与 NQ-M8（时间锚错位）均由此致害。

## 任务：

1. **材料头标「报表期／执行日」**：每条材料渲染头追加报表期与执行日两字段（additive）。
2. **期错位约束**：合同明确「材料报表期晚于执行日时，只能作为『该期资料』引用，不得据此断言执行日时点的状态」（逐字稿见下）。
3. 相对窗解析结果与材料期比对：错位时给注记（不静默）。

## 逐字稿（合同句，施工照抄）：

```
【材料期约束】材料报表期晚于执行日时，只能作为「该期资料」如实引用，不得据此断言执行日时点的状态或「当前」情况。
```
