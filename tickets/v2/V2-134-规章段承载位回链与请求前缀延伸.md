## 0. 本票一句话

把四相位（`understand`／`clarify`／`toolmatch`／`answer`）的**规章段**从「每次请求临时前置 system 条」改回「进入相位时**并入该相位的 user 首入包**」——**合同文本一字不改，只换承载位**；`repair` 相位**保持 system 位不动**（侧路无链）。

**判据（Owner 2026-10-19 裁定）＝设计符合 KV 缓存的追加形**——「同一个任务内的多轮对话符合追加形上下文即可」，即同一 run 内相邻调用的**完整请求互为前缀延伸**。**供应商是否支持缓存、命中多少，不作判据**（P6 遥测另批，见 §3.0 登记）。
