## 附 B：faq_lookup 执行语义（伪代码——施工基准）

```
def faq_lookup(question: str) -> AuxiliaryMaterial | EmptyNote:
    q = normalize_faq_question(question)          # 复用 P-051 归一单点
    hits = pg_faq.similar(q, top=3)               # 生产读面（复用 P-051 pg_faq）
    hits = [h for h in hits if h.score >= THRESHOLD   # THRESHOLD 常量钉死
            and not h.disabled]                        # 禁用条目不消费
    if not hits:
        return 机读 note "FAQ 库无命中"          # 辅助材料空集，如实
    return 辅助材料观察:                            # locator.kind = "faq_aux"
        content = 逐条「Q：标准问 / A：答案」
        source_id = faq_entry:<id>
        # 不进血缘卡（非断言素材源），不进任何闸的判面
```

**消费规则（伪代码）**：

```
clarify 相位模型可发射 {"action":"discover","discovers":[{"tool":"faq_lookup",
  "args":{"question":"<原句或子问题>"}}]}

→ 辅助材料不触发任何 precondition 闸（纯增料）
```
