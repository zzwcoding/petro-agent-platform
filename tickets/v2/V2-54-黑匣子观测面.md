## 一、架构三原则

1. **单一取材点**：黑匣子只在执行器运行收口处（`_drive` 的 finally）发射一次
   ——不在任何图节点零散加发射点。
2. **单一蒸馏定义**：`appv2/runtime/blackbox.py` 纯函数——「黑匣子记什么、
   怎么渲染」全仓只有这一处定义；帧（第①层）与回放（第②层）共享同一语义，
   渲染函数同住此模块（工具只做胶水）。
3. **双消费面零耦合**：第①层经事件流出（事件闭世界九类扩员 `blackbox`——
   帧落盘器全量存档 SSE 帧故零改动自动收录；web 对未知事件类型按现行为忽略）；
   第②层读快照表（`ConnectionManager.readonly`＋`PgCheckpointer.alist` 官方读
   面，零手写反序列化）——历史 run 与中途挂起态都可回放。

## 二、附 A · distill 载荷（appv2/runtime/blackbox.py——键名逐字）

白名单键（final 状态闭世界，新增状态键须显式入列）：
`history`（全量 role/content——模型每步看到的收窄指令与原话）｜`steps`（step/
seq/title/**payload**——发射原文随 V2-53 的 emission 键在此）｜`observations`
（**全字段 dict 原形**——locator/kind/source_id/version/trust/content）｜
`notices`｜`question_group`｜`precondition_verdicts`｜`resume_choices`｜
`answer`｜`draft`｜`verdict`｜`rounds`｜`discover_used`｜`budget_hit`｜
`pending_ask`｜`task_type`｜`window_miss_marks`｜`chain_switch_marks`｜
`decision_error`
身份面：`run_id`／`question`／`status`／`error`（异常段 final=None＝骨架记录）。
排除键（体积/噪声）：`ledger_dump`（巨体——回放工具按快照 ledger_dump 通道现
渲染重建常驻注入）、`manifests`、`executed_payloads`、`pending_*` 内部机械态。
值面纪律：`_plain` 递归降级（dataclass/非常规值→str）——黑匣子不因脏值翻车。

## 三、附 B · 事件闭世界扩员（appv2/runtime/events.py）

## 四、附 C · 执行器收口发射（appv2/runtime/executor.py `_drive`）

try 前置 `final: dict | None = None`、`run_error = ""`；except 段记录
`run_error`；finally 段 `bus.close()` 前单点：
`bus.emit(EVENT_BLACKBOX, distill(final, run_id=run_id, error=run_error))`
——completed／failed／waiting_ask／异常段四路全覆盖，时序＝流内最后一件。
