## 一、做了什么

两层黑匣子按票面落地：

- **第①层·帧升级**：事件闭世界八类→九类（`EVENT_BLACKBOX="blackbox"`）；
  执行器 `_drive` finally 单点发射 `distill(final, run_id, error)`——运行终态
  蒸馏（history 模型原话／steps 含 payload／observations 全字段／notices／判定
  面／预算面）随事件流出，帧落盘器全量存档 SSE 故零改动自动收录。四终态
  （completed／failed／waiting_ask／异常段）全覆盖，时序＝流内最后一件。
- **第②层·快照回放**：`tools/run_replay.py` 薄胶水 CLI（人读／--json／--list
  三式）——`PgCheckpointer.alist` 官方读面复用（零手写反序列化）、readonly
  会话、渲染走 `runtime.blackbox.render_snapshots` 统一语义面。历史 run 与
  中途挂起态都可回放。

架构三原则兑现：单一取材点（executor 收口）/单一蒸馏定义（blackbox.py）/双
消费面零耦合（帧自动收录＋回放工具）。
