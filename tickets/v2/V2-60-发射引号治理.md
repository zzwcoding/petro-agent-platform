## 附 A：CLARIFY_CONTRACT 追加（逐字稿——插在头行「…四动作：\n」之后、分解条之前）

```
JSON 字符串值内需要引号时（引题干原文/术语等）：一律用中文引号「」（或单引号'），
禁止写不转义的英文双引号 "——它会把字符串提前截断，整条发射作废。
错例："question": "1.3 节关于"杆柱"的算式"   ← 值内裸引号，非法
对例："question": "1.3 节关于「杆柱」的算式"   ← 值内中文引号，合法
```

（对交接稿的微调：示例词「抽油机时率」＝台账真源指标名，过不了 P-039 命名闸
「合同零业务名词」，换非台账词「杆柱」。其余逐字照交接稿。）
