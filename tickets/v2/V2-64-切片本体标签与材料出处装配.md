## 附 A：入库侧——抽取实体回写切片（本体驱动，零新增模型调用）

**落点＝`app/domains/derivatives/service.py` 的 graph 支路**（`_extract_graph` 循环内，
逐切片 LLM 抽三元组处）。它是入库五个 LLM 调用中**唯一逐切片**的，且实体类型清单
来自本体（`default_extract_config(*_ontology_catalogs())`），过三道闸（类型/依据/弃权）。

伪代码（在 `for edge in passed:` 写图之后追加）：

```python
# 本切片涉及的本体对象（过闸三元组的实体端——类型过滤后去重）
_SLICE_TAG_TYPES = ("井", "油田", "区块", "平台")     # 定位性类型（井筒/设备/措施/化验样不入标签）
tags: list[str] = []
for edge in passed:
    for label, etype in ((edge.from_, edge.from_type), (edge.to, edge.to_type)):
        if etype in _SLICE_TAG_TYPES and label and label not in tags:
            tags.append(label)
if tags:
    await self._kb.set_fragment_well(frag.id, "·".join(tags[:6]))   # 上限 6 个防膨胀
```

**新增 kb 公开面方法**（`KbFacade` 协议 ＋ `app/domains/kb/service.py` 实现）：

```python
async def set_fragment_well(self, fragment_id: str, well: str) -> None:
    """切片本体标签回写（V2-64——graph 支路抽取结果落 kb_fragment.well）。"""
    await self._fragments.set_well(fragment_id, well)
```

`FragmentStore.set_well`（`app/domains/kb/store.py`）：单行 UPDATE `kb_fragment.well`，
`updated_at=now()`。

**边界**：`well` 列已存在（`FragmentRow.well: Mapped[str | None]`）——**零迁移**；
标签串形如 `W-11井·渤中34-5油田`；图开关关的库不跑本支路（标签为空，回退报告名）。

## 附 C：装配——材料带出处（治本单点，`context.py` 一行）
