前置: V2-66（同缝 `_n0_intent_word_gate`，注入族先行）

## 背景与根因

场景对照第 19/21 条：exfil 题（发邮箱）V2 仅靠模型口头声明「未配置外发通道」且续推后仍去
取数；action 题（下调配注）被当检索题处理答「未覆盖」——V2 无外发硬闸（V1 N11）与写意图
处置（V1 N12 受控写入，V2 spec 明示不做写操作/INV-2）。V1 无词面库可移植（N11/N12 判定归
模型＋执行闸），本票新立闭世界词面族，Owner 已拍板立项（2026-10-13 场景对照修复决策）。

## 改动面

缝：同 V2-66 `_n0_intent_word_gate`，注入族之后、禁用词闸之前扩两族。命中处置与注入族
同形（零模型零执行、notice type=refused、直答收口）；步 payload `n1_gate` 分型
`outbound_refused`／`write_refused`。

**逐字稿——外发族（动词＋通道同句共现才命中，降误伤）**：

```python
OUTBOUND_VERBS = ("发到", "发送到", "发送给", "发给", "推送到", "传到", "外传")
OUTBOUND_CHANNELS = ("邮箱", "邮件", "微信", "短信", "手机", "钉钉", "飞书", "外部系统")
```

**逐字稿——外发话术**：

> 本系统只读——未配置外发通道，数据不能发往邮箱、微信等外部渠道；可在本对话内查看，
> 明细类结果可按行导出文本。

**逐字稿——写意图族（写动词＋写对象同句共现才命中）**：

```python
WRITE_VERBS = ("下调", "上调", "调到", "调成", "改成", "改为", "写入", "删除", "停用", "启用")
WRITE_TARGETS = ("配注", "配产", "计划产量", "指标", "台账", "数据")
```

**逐字稿——写意图话术**：

> 本系统只读——不做任何写入或调整，「{target}」等生产参数不在本平台变更；
> 如需变更请走线下变更流程。

（{target}＝命中的写对象词原文。）误伤面自检：23 条场景问句逐一过词面——
「把上个月完成率情况做成汇报」（做成∉动词族）、「产量完成率怎么算」（无写对象）等零命中。
