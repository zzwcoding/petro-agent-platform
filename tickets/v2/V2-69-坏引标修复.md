## 背景与根因

场景对照 rag 题（「躺井」）：答案正文引标为字面 `[n]` 占位，verdict `supported=0/cited=[]`
——答案内容正确但引用全坏，直接伤害可信度。同 run 现 `material_truncated`（渲染帽
24/47——V2-61 材料承载分形渲染的帽面）。根因假设：答案视野被帽裁剪后，起草面引用编号与
观察材料编号错位（核验 fail-closed 判 0 支撑但答案照出——核验对坏引标未拦截）。

## 改动面（两段——先取证再修）

1. **取证**：复现 rag 题形态（多观察＋帽裁剪），从起草上下文/答案/verdict 三面取证
   编号错位点（起草面 index 来源 vs 核验比对面 vs 渲染帽裁剪序）；
2. **修**（按取证结论择一或叠加）：
   - a. 引用对位兜底：帽裁剪后起草上下文只携带**被渲染子集**及其重编号映射；
   - b. 核验拦停：cited 空而答案含引标形 → 判定失败，改写/拒答（不冒充有据）。
