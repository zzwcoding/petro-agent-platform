状态: **伪代码施工稿——待 Owner 过目后实施** ｜ 来源: V2-80 方案 §4 第三步 ｜ 前置: V2-80a（提示词反转是主修复，本闸是双保险）｜ 建议实施: 80a 真机观察后

## 0. 本票一句话

理解步模型认领「直接回答」形后，加一道**零模型确定性复核闸**：用户原话含业务词面（油田／井／指标／台账／数据库／报告）任一实词＝拒认直答，程序确定性转两行式（理解行＝原话复述、指标候选＝空）照常进决策——把「模型猜错」的最坏后果从「编造直达用户」变成「多走一次管线」。带环境开关可整体回退。

## 1. 施工伪代码

```python
# appv2/runtime/graph.py（understand_node 内——parse_direct_reply 命中后）

ROUTE_GATE_WORDS = ("油田", "井", "指标", "台账", "数据库", "报告")   # 闭世界可扩
ROUTE_GATE_ENV = "UNDERSTAND_ROUTE_GATE"        # true/false，缺省 true（非法拒启动——DE-16 同款纪律）

direct_reply = parse_direct_reply(content)
if direct_reply and _route_gate_enabled() and any(w in state.question for w in ROUTE_GATE_WORDS):
    # 业务词面拒认直答（V2-80c——模型判错的最坏面收窄为多走一次管线）：
    # 确定性转两行式——理解行＝原话复述（题意锚零发明），指标候选＝空（无台账取数面）。
    understanding = state.question
    step title 用 state.question（原「无关业务——直接回答」标题不再适用）
    # 走常规 updates：understanding/metric_candidates=[] + next_intent=INTENT_DECISION
    # bus notice 一条机读：{"type": "route_gate_override", content: "直答被业务词面闸拒认——转管线"}
else:
    ...原直答路径（_direct_answer）不变...
```

- 闸词面比对对象＝**用户原话**（state.question），不是模型输出——防模型转述丢词；
- 转两行式的理解行用原话逐字（不加不改——零发明纪律）；步标题用原问句（照常进 steps/前端过程面板）；
- 机读 notice 落 run 审计面（可统计误判率）；
- 开关装载走 infra.config（FRESHNESS_GATE 同款 ${VAR:-true}＋true/false 严格二值校验，非法拒绝启动）。

## 2. 测试面

1. 闸 on＋「数据库里都有什么油田」剧本形直答输出 → 被转两行式（understanding＝原话、候选空、INTENT_DECISION、notice route_gate_override）；
2. 闸 on＋「你好」直答 → 放行（零变化）；
3. 闸 off（env false）→ 直答照旧（逐字节不变）；
4. 词面闭世界钉（六词在册；「帮我」不含实词→放行——纯寒暄不受误伤）；
5. env 非法值拒启动钉。
