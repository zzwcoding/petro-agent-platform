## 施工点（伪代码，照抄）

```python
# appv2/infra/llm_client.py :: LlmClient.complete —— 流收集完成后、构造 LlmCompletion 之前
content = "".join(parts)
if not content.strip():
    raise UpstreamUnavailable(
        alias,
        f"空正文应答（completion_tokens={completion}）——判上游异常可切备",
    )
```

- 判据只认「去空白后为空」（纯空白同判）；非空正文逐字不动、不 strip 正文（只判不改）。
- `completion` 取 usage 的 `completion_tokens`（无 usage＝0）；异常文本不含密钥（沿用既有纪律）。
- 异常类型＝`UpstreamUnavailable`（`switchable=True`）：网关既有循环负责重试同别名→切备→
  `NoAvailableRoute`；不改网关、不改 models.yaml、不改业务层。
