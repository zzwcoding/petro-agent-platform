### 附 C·确定性引号修复兜底（subtask.py，extract_plan_json 邻位）

```python
def repair_inner_quotes(text: str) -> str | None:
    """值内裸引号确定性修复（零模型调用）：逐字符扫描跟踪在串/不在串态；
    串内遇 " 且其后（跳空白）非结构字符 , } ] : → 判值内引号换「」。
    修后 json.loads 成功→返回修复文本；仍失败→None（走既有 V2-57 回喂）。"""
```
